## 重要的git版本管理命令

### 第一次

```bash
git checkout -b my-thesis # 切换分支
# create a placeholder file to have a change to commit
git add "新建文件夹.png" # 添加单个文件
git commit -m "最基本信息完善，新建文件夹.png" -m "本次添加了姓名等基本信息。但是别忘了后面double check一次。无论如何，祝自己接下来科研顺利，前途顺利！"
```

