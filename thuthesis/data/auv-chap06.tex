\chapter{结论与展望}

\section{全文总结}\label{sec:ch06-6-1}

本文围绕``AUV 自主海缆巡检''这一工程命题，针对深远海海缆资产快速增长而传统巡检手段在成本、效率与安全性上难以为继的现实矛盾，面向``弱磁目标感知不确定、近底环境复杂、传感器模态间歇失效''三类核心困难，提出声磁协同状态估计、感知不确定性驱动控制与行为树安全决策相结合的分层验证框架，并通过多场景、多噪声、多失效模式、多控制器消融及关键链路实物/半实物实验，对其算法正确性、部署可行性与适用边界给出了可追溯的证据。全文的核心工作可归纳为以下四个方面。

第一，在系统层面，本文确立了感知、估计、决策与控制四环贯通，不确定性沿层向上传递的整体架构，并将其落地为 Jetson Orin 与 PC104 双脑异步协同的软硬件形态。与把各功能模块简单串接的常规做法不同，本文的立足点在于让每一层不仅向上层输出状态量，还输出对该状态量的置信度（协方差），使上层决策与控制能够``知道自己知道多少''。这一设计把``不确定性感知''从一句口号转化为可在模块接口上核查的数据契约，也构成了后续状态估计与控制章节的共同基础。

第二，在状态估计层面，本文以误差状态扩展卡尔曼滤波（ES-EKF）为骨架，融合惯性、DVL、声学与磁场多源观测，构建了声磁协同的近底定位与海缆路由跟踪方案，并引入基于归一化新息平方（NIS）的自适应机制在线调节量测噪声。该方案在八类传感器与通信扰动场景、三种子共二十四次运行下全部完成并保持估计连续。对 35243 次真实量测更新的分源审计进一步表明，深度观测噪声被低估而 DVL 协方差过于保守；这一结果把历史混合阈值的操作性触发与标准卡方一致性检验区分开来，也为按观测源和自由度整定自适应 R 提供了直接依据。

第三，在决策与控制层面，本文采用行为树组织任务级决策、以分层任务状态机与应急切换逻辑保证安全兜底，并在运动控制层实现了将在线感知置信度纳入代价权重调制的不确定性感知模型预测控制（UA-MPC）。仿真公平口径下（同源 Bag、同一评价脚手架）的对照实验表明，模型预测控制在长短波 S 弯与发卡掉头等不规则曲率路径上优于或持平于视线制导与比例积分微分基线，其优势区恰是几何预瞄需求最强之处；R13-v2 六类代理场景正式矩阵则进一步说明，保守分源置信策略的主要收益不是横向 RMSE 的系统改善，而是在 36/36 次完成、回退为 0 的前提下，把全局控制变化率 RMS 由 0.247 降至 0.085，并通过授权模式避免把低质量观测误用为连续 TRACK 许可。近底安全方面，CBF 低/中/高 60 s 三种子矩阵在 PID 与 MPC 两种控制器下取得 18/18 有效、2.70--2.90 m 最小净空、低净空违规和穿底均为 0 的结果，同时揭示 MPC p95 上界 23.84 ms 的实时性边界；R22 原生因子闭环全矩阵进一步验证了声磁、地形与横流因子进入制导级控制闭环后的接口可运行性和求解时序预算，96/96 次运行有效，横流被识别为当前横向误差主导因子。上述结果共同印证了``按任务层级分配控制职责、让置信度参与控制风格调制、由独立安全过滤守住底线''的整体判断。

第四，在实验验证层面，本文构建了数值分析、软件在环、硬件在环与实验室四层虚实结合体系。声磁电缆探测在干净先验下通过行业标准风格的数字孪生验收，并在满足磁观测几何前提（将真值直缆重置于传感器正下方约 7.5 m 以恢复磁场可观测性）后，于中、重两档先验畸变的六自由度闭环中复现探测恢复；此处的``恢复''以场景几何重配为前提，而非在任意不利缆几何下自适应重建可观测性。磁传感器杆臂标定使平移和旋转误差分别降低 96.27\% 与 95.31\%。TMR8637 随附测试报告给出 50 Hz 附近约 20--30 pT/\(\sqrt{\text{Hz}}\) 的模组噪声，SK2301 短接实验则测得 16.877--18.342 bit 的噪声 ENOB，并在 1 s、45 Hz 相干解调下达到 0.0230 nT 的等效矢量 RMS。进一步地，45 Hz 电缆--TMR--ArUco 联合实验以 777 个对齐点获得 \(R^2=0.8792\) 的三轴复 I/Q 拟合，将器件噪声证据延伸到移动测量与相对几何反演。Jetson Orin NX 25 W/8 核 clean run 进一步给出稳态 warm/cold 求解 wall-time p95 为 34.118/36.560 ms、成功率均为 100\%。真实 PC104 的 300 s 正常链路和 79.672 s 零执行器故障矩阵验证了固件回显、5/5 自然断链、3/3 强制超时、Remote 降级、受控丢包/延迟和故障位回传；在此基础上，修正后的同步运行把 Bit5/Bit13/Bit14 接入生产 ROS2 仲裁与行为树，在同一 rosbag 时间轴完成 18/18 项验收，独立 1800 s 稳态区间的 124841 个 ArbiterStatus 样本则保持 100\% ACTIVE、目标故障状态样本为 0。由此形成了真实执行脑到任务层的同步零执行器安全证据。

综合来看，本文的主要贡献不在于宣称某一算法全面领先，而在于提出并验证了一条``让不确定性在系统各层显式流转、并据此调制决策与控制''的技术路线，并以分层、可核查的实验证据界定了这条路线当前的能力边界。

\section{研究局限}\label{sec:ch06-6-2}

本文的验证边界是主动分层的结果：将系统级计量与真机时序有意置于实物层，先在仿真与半实物层固化算法正确性与安全逻辑，从而使每类局限都对应一条清晰、可独立推进的实物验证路径，而非笼统的``证据不足''。在此定位下，本文的主要限制集中在系统级计量与场景外推。现有 ENOB 和锁相结果证明了 ADC 子链的窄带灵敏度，联合反演证明了三轴复 I/Q 与相对几何的一致性，但二者在仿真与等效实测口径下尚不能替代包含隔离供电、车体自生磁场、九参数标定及可溯源电流/距离基准的整机不确定度评定。因此，本文的 0.05 nT 结论限定为规定带宽和积分时间下的子链灵敏度量级，而不是整机绝对准确度。

在算法侧，二十四次状态估计运行、R13-v2 正式矩阵、综合极端固定权重全流程与六自由度闭环恢复给出了稳定性与机理证据，但仍存在四类高层局限。其一，统计标定：分源 NIS 仍需按观测源与自由度重新整定，鲁棒权重下的一致性覆盖尚不充分。其二，近底安全与实时性口径：CBF 与 R22 的 solver p95 上界（分别约 23.84 ms 与 24.02 ms）相对 20 Hz/10 Hz/0.3 s 三级周期预算未越界，但不等于满足 10 ms 硬实时；进一步地，单次最大求解耗时曾达约 53.27 ms，造成最高 20 Hz 周期越界率 0.006（相对 10 Hz 桥接与 0.3 s 网络接收预算仍未越界），说明求解耗时的尾部而非 p95 才是实时性的真正边界；Jetson clean run 虽使稳态 warm/cold p95 降至 34.118/36.560 ms，但约束压力档 p95 仍为 119.795/122.342 ms，且所有资源字段均为整机遥测而非进程独占归因。其三，原生耦合闭环外推：R22 全矩阵仍是离线仿真代理，120 s 固定时长专项暴露的终端尾段虽可由任务层到达即退出处理，但 R22 尚不能外推为长航时稳定闭环，也未覆盖 PVS 原生全因子性能矩阵与真机时延；PVS 原生定深定向冒烟只关闭定深定向执行链风险。其四，真机时序与安全层级：PC104 固件回显已给出应用路径 RTT 与板内接收到打包时间，但两端没有共享时钟，仍不能拆分严格单向物理时延；Bit5/Bit13/Bit14 到 ROS2 仲裁与行为树的同步零执行器状态链虽已闭合，所测仍是主机单调时钟上的触发时间，且台架电压为 0.0 V、DVL 为安全隔离值，不包含真实电源/DVL、执行机构动态或 ADC--EKF--控制全执行量链。求解 wall time、上行到达间隔和各层触发时间也不能相加为端到端闭环时延。上述限制决定了数字孪生结论向真实海况迁移时仍需真实 ADC/DVL/电压输入下的完整调度、Jetson thermal soak、共享时钟测量、检测噪声和长期重复性的共同检验；各条目对应的具体数字、机理归因与剩余验证已集中列于 §\ref{sec:ch05-5-6} 和第~\ref{sec:ch05-r13-boundaries} 节，此处不再重复展开。

\section{未来工作展望}\label{sec:ch06-6-3}

结合上述局限，未来工作可沿四个方向递进推进，前两项属短中期的仿真内补强，后两项属面向工程交付与能力扩展的长期方向。

\textbf{其一，缩小仿真与现实的差距，推进 Sim-to-Real 迁移。} 沿分层验证阶梯向实物推进的下一刻度是场景真实性与系统级硬件验证，因此首要工作是把算法从数字孪生稳健地迁移到真机。目标平台独立求解器的短时 clean run、整机资源曲线、PC104 固件回显、PC104--ROS2--行为树同步零执行器安全链和当前拓扑 30 min 稳态已经完成；下一批可独立交付单元应收敛为：磁传感器--ADC--计算平台采集链的长时噪声与稳定性表征、等效通电电缆的可溯源横向/等效深度反演、载荷舱电磁干扰与磁卫生量化、真实 ADC/DVL/电压输入下的 EKF--行为树--控制--PC104 全执行量链、Jetson \texttt{tegrastats} thermal soak、约束压力档 deadline/fallback 对照、共享时钟下的单向通信时延，以及执行机构与水域安全验证；上述单元各自闭环、互不阻塞，可在完整总装条件具备前逐项推进。域随机化通过在训练阶段主动扰动仿真参数以覆盖真实分布，被证明是弥合仿真与现实差距的有效途径\cite{tobin2017domain}；进一步地，以数字孪生为闭环载体、驱动 AUV 集群协同探测的最新实践，为仿真训练、真机部署与在线回灌的持续迭代提供了可借鉴的范式\cite{yan2026digitaltwin}。后续应在本文的四层实验体系上补齐真实检测噪声注入与多种子统计，以 45 Hz 可控激励复验 TMR8637-\/-SK2301-\/-DLIA 完整链路的输出噪声与等效噪声带宽，并另行评估 50 Hz 电网工频场景的适用性，逐步引入真机转台标定与实海况数据回灌。

\textbf{其二，深化不确定性感知控制，引入学习型与随机模型预测控制。} 本文的 UA-MPC 以人工设计的置信度与权重映射为主，未来可向数据驱动的自适应方向演进。学习型模型预测控制系统性地讨论了如何在保证安全的前提下用数据改进模型与代价，为在线学习环境模型提供了理论框架\cite{hewing2020learning}；带不确定性传播时域的随机非线性模型预测控制，则从概率约束的角度给出了在预测时域内显式传播不确定性的具体做法，与本文``协方差沿层流转''的主线高度契合，可作为把置信度更严格地纳入优化问题的下一步\cite{zarrouki2024stochastic}。

\textbf{其三，提升海缆探测的智能化水平。} 本文的探测链路以物理建模与解析反演为主，未来可引入面向 AUV 巡检的实时智能检测方法，把学习型感知与本文的声磁协同估计相结合，以提升在复杂地形与强干扰下对海缆目标的实时识别与跟踪能力\cite{bodenmann2024realtime}，从而把``前置筛查''的召回率与鲁棒性进一步抬高。

\textbf{其四，扩展作业能力，迈向多 AUV 协同与持久自治。} 面向深远海大规模周期性巡检，单台 AUV 的续航与覆盖能力终将成为瓶颈。一方面可发展多 AUV 协同编队以并行覆盖长距离路由。多自主水下航行器编队控制的系统综述表明，领航跟随、虚拟结构与基于行为等编队范式各有适用边界，而水声通信的低带宽、高时延与拓扑时变则是其区别于陆空编队的核心约束\cite{yan2023formation}；与之相辅相成的是协同定位，即让编队内的 AUV 通过相互测距与信息交换来抑制各自惯导的长期漂移。近期基于最大熵原理的鲁棒协同定位方法进一步说明了在量测野值与非高斯噪声下如何保持定位一致性\cite{li2025cooplocalization}，这与本文``协方差沿层流转、并以一致性检验守护估计可信度''的主线在多机层面上完全同构，可视为把单机不确定性感知思路推广到编队尺度的自然延伸。另一方面，驻留式 AUV 与水下对接技术为长航时、免母船值守的持久自治作业提供了可行路径\cite{curtin2018resident}，使 AUV 能够在海底基站就地充电与数据回传，从而把巡检从``单次出海任务''升级为``常驻式持续监测''。

总体而言，上述四个方向由近及远地勾勒出从``算法层面正确''走向``工程可交付''的完整路线：短中期并行推进仿真统计补强与现有实物子链集成，长期完成整艇水域验证与多机协同持久自治。沿``仿真建基线、分层实物验接口、整艇闭环作最终验收''的顺序推进，可以在不依赖一次性满足所有条件的前提下，逐步把本文技术路线的实证强度抬升到工程交付水平。
