## 一、全局风格问题（已成型的横切结论）

以下是抽样后跨图族的**共性问题**，逐图记录只标注个例增量：

1. **【风格未统一】三套字号/配色体系并存**：
   - (A) architecture draw.io：思源宋体，蓝/绿/黄/紫分层，风格统一、最规整；
   - (B) tools/*.py matplotlib 论文图（terrain/mpc_test）：字号偏大、标题英文、seaborn 调色板，较协调；
   - (C) 早期实验脚本图（bt_vs_fsm/mag_extrinsics/operator）：**默认 matplotlib 风格**，字号小、配色为 `tab:orange/tab:blue` 原色或纯默认，与 (B) 明显不一致。
   - → **整改方向**：抽出统一 `setup_style()`（字号、字体、配色、网格 alpha、figsize 宽度按 A4 正文宽 ≈14–16cm 折算），（C）类图优先套用。
2. **【中英混排不一致】**：正文与 caption 用中文，但绝大多数图内标题/轴标/图例是英文（且部分脚本 `_ascii_label` 把中文强转 ASCII）。学位论文需统一——建议**图内文字统一中文**（脚本已有中文字体注入范式，见 bt_vs_fsm L45-54），或全文接受"图内英文+中文 caption"并在凡例中说明。
3. **【A4 可放性】**：多数单图长宽比 OK；**宽横图**（2148×1263、4169×2971 等）缩到正文宽后**字号会显著变小**，需要在源码里增大 `fontsize` 而非依赖导出缩放。**双栏合并图**（05_mpc_combined_summary 2×2、terrain_tz 上下 2 图）在 A4 单栏下每个子图偏小，考虑拆分或加大。
4. **【"文本截图"类图】**：`operator_acceptance_summary_*` 是把纯文本用 `ax.text(...monospace)` 渲染成 PNG——**不适合作为学位论文正式插图**，大量留白、无信息图形。建议**转成三线表**进正文，或降级到附录。
5. **【caption 缺失】**：正文所有 `![中文alt](path)` 均无正式图题（图 X-Y + 说明 + 数据来源/n 数）。需按「图 5-x 标题（数据源，n=?）」统一补。

### 6.4 图内中文化 — 统一操作方法（SOP）

**统一字体注入片段**（放各脚本 `setup_style()` 或绘图入口，文泉驿正黑）：

```python
import matplotlib.font_manager as fm
import matplotlib.pyplot as plt

_ZH_FONT = "/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc"
def apply_zh_style():
    if os.path.exists(_ZH_FONT):
        fm.fontManager.addfont(_ZH_FONT)
        name = fm.FontProperties(fname=_ZH_FONT).get_name()  # "WenQuanYi Zen Hei"
        plt.rcParams["font.family"] = name
    else:
        plt.rcParams["font.sans-serif"] = ["WenQuanYi Zen Hei", "SimHei"] + plt.rcParams["font.sans-serif"]
    plt.rcParams["axes.unicode_minus"] = False   # 关键：负号用 ASCII，避免中文字体缺 U+2212 变方块
    # A4 正文宽 ~14–16cm，字号整体上调
    plt.rcParams.update({"font.size": 12, "axes.titlesize": 14, "axes.labelsize": 12,
                         "legend.fontsize": 11, "figure.dpi": 160, "savefig.dpi": 300})
```

**中文化步骤**（每个脚本）：
1. 在绘图入口调用 `apply_zh_style()`（terrain 已有 `setup_style()`，补字体块即可；bt_vs_fsm 已有 L45-54，只需把英文 title 文本改中文）。
2. 逐条把 `set_title/set_xlabel/set_ylabel/legend(label=...)/suptitle` 的**英文字符串改成中文**（保留数值/单位，如 `"Clearance RMSE to 3 m (m)"` → `"离地净空 RMSE（目标 3 m，单位 m）"`）。
3. `axes.unicode_minus=False` 必设，否则负号方块。
4. `_ascii_label()`（operator/scorecard）：中文化时**不要**再强转 ASCII，直接用原文本（这两张是 C 类，按决策 2 本轮不深改，保证不崩即可）。
5. 重跑 → 输出到脚本默认目录 → 迁移入 `docs/thesis/figures/...`（沿用各组 `_SOURCE.md` 的迁移约定，保留 provenance）。
