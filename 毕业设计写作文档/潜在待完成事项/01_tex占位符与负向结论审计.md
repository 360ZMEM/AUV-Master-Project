# 01 Tex 占位符与负向结论审计

## 1. 文档目的

本文只审计最终论文源 `thuthesis/data/auv-chap01.tex` 至
`auv-chap06.tex`，用于完成三件事：

1. 找出显式占位符、未完成实验、负结果和反复出现的证据边界；
2. 判断相关内容是已经有证据、可以补实验，还是必须留给实物阶段；
3. 为后续重写 Tex 提供删除、替换、集中保留的逐项依据。

本文不直接修改 Tex。后续改写遵循“过时内容整段删除后重写”的规则，不在
Tex 上做零碎补丁。

## 2. 总体诊断

按二级标题统计，包含“待补、尚未、缺失、不足、不能、失败、负结果、不成立”
等词的正文行共有 132 行：

| 章节 | 命中行数 | 主要集中位置 |
|---|---:|---|
| 第 1 章 | 6 | 研究背景、创新点、组织架构 |
| 第 2 章 | 21 | 仿真/实物能力、磁模型、通信与电气隔离 |
| 第 3 章 | 15 | 时间同步、DLIA、磁反演、状态估计验证 |
| 第 4 章 | 16 | 行为树、轨迹扫描、MPC、极端工况 |
| 第 5 章 | 65 | 结果讨论、缺失实验、极端场景和章末总结 |
| 第 6 章 | 9 | 研究局限与未来工作 |

问题不是“论文没有主动说明边界”，而是边界说明已经过量。相同限制在方法章、
实验章、章末小结和结论章重复出现，削弱了正向结果的连续叙述。推荐采用以下
收敛规则：

- 方法章只保留一次必要的适用条件，不写实验待办；
- 第 5 章每项实验只在结果表脚注或段末保留一句证据等级；
- 负结果集中到 §5.6 的一张“负结果、归因、处置”表；
- 未完成实验不在第 5 章铺开方案，统一移到 §6.2/§6.3 和本目录；
- “不能支撑什么”不在每节重复，章末只保留一次；
- 已经通过后续实验翻转或闭合的旧负结果，正文只写最终因果结论，过程移到附录。

## 7. Tex 构建审计（Batch 0 已闭环）

### 7.1 唯一权威源

自 2026-08-09 起，论文的唯一可信正文与参考文献源为：

```text
thuthesis/data/auv-*.tex
thuthesis/ref/auv-references.bib
```

`docs/thesis/paper/*.md` 及其他 Markdown 只保留为历史材料和外围实验记录，
不得再自动覆盖 Tex。`make auv-thesis` 已移除
`migrate_thesis_chapters.py --check` 和 `sync_latex_references.py --check`，
构建过程不再读取、迁移或同步 Markdown。旧迁移脚本不得对当前维护中的
Tex/Bib 执行写入操作。

### 7.2 已修复的构建故障

1. 移除把 Markdown 判定为 canonical source 的 `STALE` 前置检查；
2. 用 `make clean-auv-thesis` 清除含其他平台绝对路径和版本信息的旧辅助文件；
3. 将 `auvsetup.tex` 中当前 TeX Live 2022 不提供的 `\gbleftbracket`、
   `\gbrightbracket`、`\SlashFont` 和 `titletypedelim` 改为兼容写法；
4. 保留“正式出版物不因含 DOI 被误标为 `/OL`”的 GB/T 7714 类型逻辑；
5. 在 Makefile 中增加最终产物与日志门控：PDF 必须非空，最终日志不得残留
   undefined command/citation/reference、Biber 重跑或交叉引用重跑请求。

### 7.3 验证结果

在 `thuthesis/` 先清除辅助文件，再执行完整构建：

```bash
make clean-auv-thesis
timeout 300 make auv-thesis
```

随后直接执行一次增量构建：

```bash
timeout 300 make auv-thesis
```

两种构建均以退出码 0 完成。完整构建经过 XeLaTeX、Biber 和 `xdvipdfmx`，
最终产物为 `thuthesis/auv-thesis.pdf`：

| 验收项 | 结果 |
|---|---:|
| PDF 页数 | 175 |
| PDF 大小 | 13,895,014 bytes |
| 页面规格 | A4 |
| Biber 实际条目数 | 90 |
| undefined command/citation/reference | 0 |
| 残留 rerun 请求 | 0 |
| `Overfull \hbox` | 0 |
| `Underfull \hbox` | 19 |

19 处 `Underfull \hbox` 是摘要、长英文参考文献和附录窄表格中的局部排版
松散，不阻断构建，也不表示内容或引用缺失。当前系统只提供 `C.utf8`，
而会话环境声明 `zh_CN.UTF-8`，因此 Perl 会输出 locale 回退警告；该警告
不影响 XeLaTeX、Biber 或 PDF 内容。考虑 Makefile 还需在 Darwin 平台使用，
暂不硬编码 Linux 专属 locale。

### 7.4 Batch 0 后续非阻断项

1. 在宿主环境安装或正确声明 UTF-8 locale，消除 Perl 环境警告；
2. 论文内容稳定后逐项压缩 19 处 `Underfull \hbox`；
3. 占位符静态扫描暂不设为构建失败条件，因为本文件登记的正文占位仍需按
   Batch 1 以后逐项消除；待占位清零后再升级为硬性门控；
4. 跨平台切换后若辅助文件版本不兼容，先执行 `make clean-auv-thesis`，
   但不得运行 Markdown 迁移或参考文献同步脚本。
