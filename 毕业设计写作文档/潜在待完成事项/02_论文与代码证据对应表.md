# 02 论文与代码证据对应表

## 1. 使用规则

本文建立 `thuthesis` 二级标题到代码、配置、实验入口和结果产物的映射。
后续 Tex 重写遵循以下规则：

- 方法结论必须能定位到算法或部署代码；
- 实验结论必须能定位到输入配置、运行入口和结果产物；
- 只有接口、没有运行结果的内容写成“实现”而不是“验证”；
- 子仓库结果必须注明是算法级、主仓闭环级还是硬件实测级；
- 代码中的备份文件、安装态旧副本和未跟踪草稿不能作为论文证据。

## 10. 证据引用最小模板

每个 Tex 实验段落至少具备：

1. 实验问题；
2. 对照变量；
3. 样本量与有效运行数；
4. 主指标和失败指标；
5. 一句适用范围；
6. 外围文档中的代码、配置、结果路径。

正文不写 shell 命令、环境变量、日志目录和调试过程；这些全部保留在本目录、
`docs/experiment/`、`rating.md` 和代码仓 README 中。
