# 分源置信度部署实施记录

## 1. 本轮边界

首轮完成 P0--P4 的分源质量基础设施；后续主线衔接又完成 P5 权限 shadow 和
P6 保守控制接口的前置实现。P5 输出仍被硬标记为 shadow，P6 默认关闭且拒绝
shadow，因此现有行为树、实物自治权限和已归档 MPC 结果均未改变。

旧 `SensorStatus.confidence` 和 MPC 协方差映射暂时保留，用于兼容既有实验；
它们不再被视为声呐或磁探测置信度。

## 2. 已完成内容

### 2.1 分源消息契约

新增四个 ROS2 消息：

- `MagneticSampleBlock.msg`：保存完整波形、相对时间、采样率、丢包、削顶、
  标定和采样时钟状态；
- `SonarCableObservation.msg`：保存声呐检测点、检测器分数、CNR、可见长度、
  候选歧义和视场截断；
- `PerceptionQuality.msg`：统一输出来源、有效性、原因码、检测证据、概率、
  电缆相对估计、协方差和标定版本。
- `CableTrackingAuthority.msg`：分开记录传感器健康、检测许可、跟踪许可和
  TRACK/SEARCH/HOLD 状态，不再复用 `SensorStatus.confidence`。

概率字段遵循以下规则：

1. 无独立验证集批准的标定文件时，`p_detect` 和 `p_track` 必须为 NaN；
2. 检测与跟踪分别记录标定状态；缺少几何上下文时可有已标定
   `p_detect`，但 `p_track` 仍必须为 NaN；
3. `detection_score` 始终保留，便于离线标定；
4. 未观测的状态分量及协方差为 NaN，不以零代替未知；
5. `VALID/DEGRADED/INVALID` 与原因码独立于概率。

### 2.2 磁质量估计

磁链不再使用三轴总场模长除以固定 `0.05 nT`。新算法对完整三轴块执行
带 Hann 权重的 45 Hz 正余弦回归，并同时估计常量项和线性漂移：

\[
\mathbf B_a(t)=\mathbf b_{0,a}+\mathbf b_{1,a}t+
\mathbf c_a\cos(2\pi f_0t)+\mathbf s_a\sin(2\pi f_0t)+\epsilon_a .
\]

残差给出六维 I/Q 系数协方差，检测统计量为

\[
T=\hat{\boldsymbol\beta}^{\mathsf T}
\Sigma_{\beta}^{-1}\hat{\boldsymbol\beta}.
\]

在高斯零假设下使用六自由度卡方尾概率形成
`detection_score=-log10(P_FA)`。该量是检测证据，不伪装为后验概率。

若提供电缆航向和垂直距离，使用同相复向量比值估计横偏，并通过数值
Jacobian 将 I/Q 协方差传播到横偏方差。缺少几何上下文时仍可报告 45 Hz
证据，但横偏与 `p_track` 保持不可用。

FK2301 客户端现保留完整标定波形，而不是只取最后一个点。完整块最多 5 Hz
发布，原 `/auv/sensors/magnetic` 单点接口保持兼容。当前时间轴仍由设备报告的
名义采样率重建，因此明确发布 `sample_clock_verified=false`；在时钟验证完成前，
磁质量只能是 shadow/degraded。

### 2.3 声呐质量估计

声呐质量层消费检测点而非任意置信标量。实现采用加权 TLS 与 Huber IRLS
拟合电缆线，输出横偏、航向和几何协方差。质量证据包含：

- 有效点数和有效样本数；
- CNR；
- 可见长度；
- 第一/第二候选歧义裕度；
- 稳健残差与内点率；
- 视场截断和数据新鲜度。

外部检测器 `valid=false`、观测陈旧或内点率过低时，结果不能进入 VALID。

### 2.4 概率标定门

新增 `tools/calibrate_perception_quality.py`。输入 CSV 必须包含：

```text
detection_score,track_score,detected,within_tolerance
```

脚本使用 pool-adjacent-violators 拟合单调 isotonic 曲线，并要求独立验证集同时
满足：

- 默认至少 100 个样本；
- detection 与 track 各至少 20 个正样本和 20 个负样本；
- Brier score 不高于 0.20；
- ECE 不高于 0.10。

未提供独立验证集或任一门控失败时，产物
`deployment_approved=false`，运行时不会使用其中的概率曲线。

### 2.5 ROS shadow

`perception_quality_node` 默认随主栈启动，发布：

```text
/auv/perception/quality/magnetic
/auv/perception/quality/sonar
/auv/perception/quality/diagnostics
```

它不发布 `SensorStatus`、不修改 `Setpoint`，也不连接 MPC。现阶段仅用于录包、
标定和风险审计。

## 3. 当前验证

### 3.1 单元测试

已覆盖：

- 45 Hz 目标对 50 Hz 强背景的选择性；
- 45 Hz 横偏和协方差传播；
- 削顶输入失效；
- 声呐线拟合异常点抑制；
- 声呐 detector invalid 门控；
- isotonic 单调性、Brier/ECE 与边界插值；
- FK2301 完整块和时间轴保留。

### 3.2 ROS smoke

合成磁块：

```text
cross_track = 3.75 m
detection_score = 300
validity = DEGRADED
reason = sample_clock_unverified, probability_calibration_missing
p_detect = NaN
p_track = NaN
```

合成声呐线：

```text
cross_track = 1.200 m
heading = -0.00194 rad
detection_score = 9.498
validity = DEGRADED
reason = probability_calibration_missing
p_detect = NaN
p_track = NaN
```

两项结果都证明消息、算法和 ROS 发布链可用；不构成现实概率标定证据。

### 3.3 R13 仿真替代链

R13 的 PVS/protocol_udp 路径实际由 `mock_amd_server.py` 驱动，而不是
`holoocean_physics_bridge.py`。现已在 Mock AMD 的 Zenoh 旁路新增两类原始测量：

```text
rt/auv/sensors/magnetic_block
rt/auv/sensors/cable_sonar_observation
```

磁块按 2 kHz 生成至少 0.18 s 的三轴波形，含 45 Hz 目标、50 Hz 干扰、DC 背景和
场景磁噪声；声呐观测把电缆几何投影到 AUV body frame，再施加视场、量程、点噪声
和候选质量。truth 只用于生成测量，不进入概率字段。现有单点磁场和前视地形声呐
保持不变，后者仍只服务地形预瞄。

单导线 500 A Biot--Savart 场不能直接当作三相海缆的 45 Hz 可观测剩余量，否则
六场景磁检测全部饱和。仿真测量模型因此显式设置 `target_signal_scale=0.002`，
表示三相抵消、屏蔽和耦合后剩余的目标频率分量。该数值只用于让代理场景获得可用
动态范围，必须由 M0/M1/M4 实测重新辨识，不能回填为实物比例。

离线 preflight 以固定 seed 扫描六个代理配置和三档横偏，不启动 PVS、ROS 或
MPC。当前结果为：

| 检查项 | 结果 |
|---|---:|
| 六场景双源覆盖 | 通过 |
| measurement 中无 confidence/probability 直写 | 通过 |
| sonar `p_track` 范围 | 0.589--0.970 |
| sonar `p_track` 跨度 | 0.381 |
| magnetic `p_detect` 范围 | 0.739--0.990 |
| magnetic `p_detect` 跨度 | 0.251 |
| 仿真标定误作实物批准 | 否 |

仿真概率曲线使用 `calibration_domain=simulation_proxy`，并明确
`physical_deployment_approved=false`。默认实物参数只接受 `physical` 域，
不会加载该曲线。

## 4. 下一阶段数据计划

### P3-M：磁标定

1. M0：无 45 Hz 电缆激励，覆盖电机开关、推进器档位和不同姿态，形成零假设；
2. M1：已知横偏、航高和电流，覆盖检测边界；
3. M4：至少五档已知场强，验证幅值、削顶和动态范围；
4. 训练/验证按采集 run 分组，禁止同一 run 的相邻窗口跨集合；
5. 分别标注 `detected` 与 `within_tolerance`。

### P3-S：声呐标定

1. 获取声呐算法原始检测点或 mask，不能只保留厂商 confidence；
2. 用已知电缆几何或同步外部定位生成横偏/航向真值；
3. 覆盖埋设、遮挡、边缘视场、多候选和空场景；
4. 按航段或实验 run 划分训练与验证；
5. 对不同声呐固件和检测模型分别维护 calibration ID。

### P5：决策权限 shadow 已完成

1. `tracking_authority_node` 已独立实现 TRACK/SEARCH/HOLD；
2. `p_track` 使用进入/退出双阈值和连续帧去抖；
3. runtime sensor health、`p_detect` 和 `p_track` 分别门控；
4. 磁源可只提供检测许可，不能因缺少几何上下文伪造跟踪许可；
5. 当前节点硬编码 `shadow_only=true`，只发布
   `/auv/perception/cable_tracking_authority_shadow`，不接行为树或自治总许可。

P5 剩余工作是用真实独立验证集批准的 calibration ID 完成 shadow/active 同输入
对照，再另行评审 active 节点；不能通过修改当前参数直接取得实物权限。

### P6：保守控制前置接口已完成

1. 控制器新增 `quality_control.enable=false` 默认门，且默认拒绝 shadow；
2. 显式接入时先按 `p_track` 降速，再把不确定性映射为
   `delta_u_penalty_scale`；
3. MPC 新增 `confidence_policy=conservative`，低置信时降低横向跟踪权重、
   提高控制代价，并支持航向、深度和推力的 \(\Delta U\) 代价；首个预测控制量
   现在显式相对上一周期实际输出计算增量，而非只惩罚预测域内部差分；
4. 旧 `legacy_aggressive` 仍为默认，仅用于复现既有实验，不再作为下一轮
   R13 的允许配置；
5. `safety_margin_scale` 已进入接口和逐周期诊断，但当前运动学 MPC 尚无可直接
   收紧的障碍/概率约束，因此它尚未作用于优化约束，不得写成已完成机会约束。

仿真可显式允许 `simulation_proxy + shadow` 驱动控制；实物路径仍必须同时满足
物理标定域、非 shadow authority 和 P5 active 评审。

R13-v2 的离线权重矩阵已冻结 `delta_psi_cmd=50.0`、
`delta_z_cmd=10.0`、`delta_T_cmd=2.0`。该组在 R14 快照和短 S 弯中无 fallback
或 50 ms 阻塞，并将归一化控制变化率降低 2.24%，只作为
`simulation_proxy` 的下一轮实验配置。单场景双模式 repair pilot 中，磁质量和
声呐质量各发布 51/52 帧，UA 的 `p_track` 非常量、policy 全部接受，且未发生
fallback 或周期阻塞。

首轮 pilot 暴露了一个诊断层错误：磁源按契约不提供 `p_track`，其合法 NaN 被
严格 JSON 编码拒绝，导致质量节点退出。现仅在 diagnostics JSON 中递归映射为
`null`，ROS `PerceptionQuality` 中的未标定 NaN 语义保持不变。失败包和 repair
provenance 均保留。

### P7：正式实验

1. 单独报告声呐、磁与融合的可靠性图、Brier、ECE、虚警率和 risk-coverage；
2. 做单源失效、陈旧、冲突、削顶、丢包和标定错误注入；
3. 通过后重跑六场景×两模式×三 seed×60 s；
4. Jetson 独占资源验证 45 Hz DSP、ROS 传输和控制周期。
