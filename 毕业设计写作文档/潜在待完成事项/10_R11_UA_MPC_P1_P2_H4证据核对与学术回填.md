## 3. 独立复核结果

### 3.1 P-1 可解性归因

按诊断帧数对运行级回退率加权后，A0、A1、A2、A3 的回退率分别为
1.000、0.699、1.000 和 0.335。固定权重与关闭 sigmoid 降权均全程回退；
保留 sigmoid 降权后恢复部分求解成功。因此，低置信度控制代价降权是
可解性改善的必要机制，线性置信度映射只在该机制存在时提供进一步收益。

### 3.2 P-2 最大迭代次数

`max_iter=100/200/400` 时，诊断帧数分别为 1027/1024/761，事件加权回退率
分别为 0.699/0.685/0.594，当前可观测失败占用分别为
88.41/192.21/372.20 ms。400 档仍有 59.4% 回退，且诊断帧相对 100 档减少
约 26%。因此，增加迭代上限只能有限降低回退，并会阻塞 100 ms 控制周期；
默认值保持 100。

`FALLBACK_LAST_OUTPUT` 复用上一成功输出，其中的 `solve_time_ms` 是陈旧值。
论文只引用成功帧求解时间和当前可观测 `FALLBACK_SETPOINT` 失败占用，不把
普通全帧均值解释为当前失败耗时。

### 3.3 H4 横向精度归因

长波 S 弯中，A0/A1/A2/A3 的横向 RMSE 分别为
0.0852/0.0754/0.0852/0.0740 m。A1 相对 A0 改善 11.6%，关闭 sigmoid 的
A2 退化回 A0；A3 相对 A1 仅再改善约 1.9%。因此，sigmoid 控制代价降权
也是横向精度主贡献，`confidence_alpha=1.0` 只提供边际收益，默认
`confidence_alpha=1.5` 保持不变。

发卡路径首次到达 99% 进度前，四个变体的 RMSE 均约 0.10 m；全时段约
3.2 m 的 RMSE 主要来自约 52 s 完成路径后车辆继续前进。该现象归因为
terminal stop 缺失，而不是 180 度转弯段跟踪失败。

## 4. 论文表述契约

正文可写：

1. sigmoid 控制代价降权是可解性与横向精度的主贡献；
2. 单纯提高 `max_iter` 不能工程化修复高回退；
3. 线性置信度映射只有边际精度收益，不足以修改默认参数；
4. 发卡全时段大误差来自终端停止条件缺失。

正文不可写：

1. `max_iter=400` 改善了实时性能；
2. H4 证明六自由度或真机精度提升；
3. `confidence_alpha=1.0` 是新的最优默认值；
4. 把陈旧的上一输出求解时间当作当前失败帧耗时。
