# 扰流、导航误差、多源干扰与毕业答辩稳健性目标

日期：2026-09-29。来源：用户本次持续目标。当前状态：完成（声明条件下的仿真与答辩资产范围，实物部署另验）。

## 用户原始目标（永久保存）

> 现在我们按照接下来一个主要方向继续，就是适当增强一些对于扰流，导航误差，多源等干扰，将目前实验的边界相对明确，且无可指摘。这些内容预计也可以在某种意义上提供一些进一步的诊断要素，也可以解决一些目前存在的对于答辩比较高风险的边界。也因此，需要总结目前尚存的边界，对于答辩的印象，综合修改难度进行一并处理，减少高危边界（以硕士生实施的巡检系统为边界，这意味着系统可以不完整，可以考虑不周全，但是架构完整，创新点明确）实物部署暂时不计入内。一并提供重要的图像，面向答辩外部观察和指标证据，matplotlib（和前面一同风格化等），从而让目前的资产面向毕业完整，而非绝对应用完整，这意味着不是没有缺点，而是缺点不对答辩和实物toy experiment有致命影响，但是不出现答辩所致问题。

## 工作边界与完成条件

1. 检查当前源码与历史证据；将风险、答辩影响、修复成本和剩余假设一起登记。实物部署、Jetson 实时调度和 PC104 收帧不纳入本轮完成条件。
2. 使用当前原生磁算法、既有 PID、72 字节协议与原生 PVS，在同一版本和同一评价口径下增强扰流、导航误差、多源、组合干扰与拒绝案例；不覆盖图 71 或旧实验原始资产。
3. 优先修复错误授权，而非为提高成功率调低门限。新增诊断／监督模块独立 opt-in，接口兼容；参考目标区间等输入必须明确是 toy 条件，不能暗用评价真值作决策。
4. 同时报告任务完成、正确拒绝、错误通过、全核心真实横偏、覆盖、异常延迟、撤权后运动；不按业务 stage 筛掉回归修正，不把零命令当作停止运动，不把声明误差界当成已证明的实际误差界。
5. 参数先声明，开发与留出种子分开；旧单源理想导航结果重算仍有效，新版本差异可解释。有限网格不外推为任意海况或多源识别保证。
6. 提供同源宋体／Fandol matplotlib 的巡检地图、干扰诊断过程和指标／边界图，独立报告、复现命令与原始数据入口；同步必要的论文／PPT 答辩表述，保留 169 页论文的精简原则。
7. 逐项审计以上交付与行为，全部有证据后才标记持续目标完成；缺证据则继续执行。

| 优先级 | 现存边界 | 答辩风险 | 可行处理与成本 |

| P0 | 低协方差的固定偏差／漂移仍可能错误通过 | 协方差被误讲成实际误差证明 | 加时间一致性诊断和外部位置基准；真实误差与在线代理分开；低至中 |
| P0 | 小流／突变流下仅用旧扫描前馈或迟到撤权 | 强调扰流鲁棒却不报失效边界 | 同版稳态、周期、阶跃、超界及组合对照；启用已有突变门或补独立监督；中 |
| P1 | 深度宽度系数及未知三维／多芯场仍不可辨识 | 横向完成被误讲成埋深完成 | 沿用独立深度许可和已有失配反例，当前埋深为空；低 |

| P1 | 曲率、一次扫描后的观测陈旧与固定接入配方 | 限定直线成果被当通用路线 | 增加缓变／超界反例或明确直线短段条件，不做复杂重规划；中 |
