# 07 R03 五类实验边界与 45/50 Hz 频率语义契约

## 1. R03 结论

R03 固定两项契约：

1. 五类实验按“当前阶段缺少的依赖”分类，分类边界以
   `04_章节级实验方向与执行顺序.md` §1 的总表为准；
2. 论文中的 50 Hz 不能全局替换。电网工频、产品工作频点、供应商谱线和器件
   参数保留其原始频率；本文已完成和后续可控实验统一采用 45 Hz，并在结果中
   分开记录激励频率、解调参考频率和数据来源。

当前全 Tex 定点审计得到：

- 已完成的 45 Hz 电缆+ArUco 联合实测在 `fit_summary.json` 中有机器可读频率；
- 两个原始 NPZ 均没有保存 `excitation_hz` 或 `reference_hz`，属于旧采集契约缺口；
- Tex 中显式 45 Hz 命中为 0，50 Hz 相关命中为 28 行；
- 28 行中 20 行应保留来源原值，1 行是深度传感器更新率，7 行需要在 R10
  泛化为 \(f_0\) 或改回本文 45 Hz 实验口径；
- `default_config.yaml` 和 `user_config.yaml` 的 50 Hz 只是当前软件默认值，
  不能反推旧 NPZ 的真实采集或分析频率。

本任务固定语义和修改队列，不提前执行依赖 R05、R06、R07 的 R10 批量正文重写。

## 2. 五类实验的判定方法

### 2.1 唯一判定顺序

| 判定问题 | 是 | 否 |
|---|---|---|
| 当前结论是否依赖专用计量器材或可溯源物理真值？ | 类别 5 | 继续 |
| 是否需要在已有 TMR8637/SK2301 上新增采集？ | 类别 4 | 继续 |
| 是否必须在 Jetson/PC104/AUV 上运行？ | 类别 3 | 继续 |
| 是否缺分析器、记录字段、基线算法或场景模型？ | 类别 2 | 类别 1 |

分类对象是一个可验收阶段，不是整个研究主题。例如“45 Hz 磁实验”不是一个类别：
旧 NPZ 的探索性复核属于类别 1，无头分析器属于类别 2，TMR 重新采集属于类别 4，
可控电流与埋深台架属于类别 5。

### 2.2 当前任务到五类的映射

| 类别 | 当前任务 | 进入条件 | 完成边界 | 直接后续 |
|---:|---|---|---|---|
| 1 | 旧 NPZ 定点复核、NIS 审计、已有 sweep 重聚合、UA-MPC 既有结果归因 | 输入和指标已经存在 | 只产生当前数据层上的统计与解释 | R05、R07、R11、R13 |
| 2 | R04 运行产物契约、R06 无头 DLIA、实测噪声 replay、原生声磁场景、MPC 可解性诊断 | 可在本机开发和测试 | 工具、schema 和确定性回归通过，不宣称实物结果 | R08、R15、R19、R21 |
| 3 | Jetson clean benchmark、PC104 链路与执行器分级 handoff | 一键 bundle 和返回包契约已就绪 | 指定平台/版本/工况的性能，不外推海试 | R23、R25 |
| 4 | M0--M7 TMR/SK2301 采集 | R04、R06、R08 完成 | 短期链路噪声、相对幅相、检测概率和状态磁噪声 | R24、R26 |
| 5 | 九参数转台、可控电流/埋深台、电源纹波/ENOB/屏蔽计量 | 器材、真值和不确定度方案齐备 | 给定台架条件内的计量或绝对精度 | R27--R29 |

### 2.3 不允许的分类方式

| 错误方式 | 原因 | 正确处理 |
|---|---|---|
| 一个任务长期标成 `1/2/4/5` | 无法判断当前阻塞条件 | 拆成分析器、重分析、补采、计量四个阶段 |
| 有真实传感器数据就直接归类别 5 | 实物不等于计量 | 普通短时采集归类别 4；只有可溯源真值才归类别 5 |
| 工具代码写完就把实验记为完成 | 类别 2 只证明基础设施 | 数据运行另开类别 1、3、4 或 5 任务 |
| Jetson 上运行就称系统实物验收 | 算力平台不等于 PC104/AUV/传感器全链 | 只写指定 Jetson 工况的算力与热稳定 |
| 类别 5 未完成但在正文保留多处占位 | 破坏论文叙述 | 仅在 §6.2/§6.3 集中保留一次 |

## 3. 45/50 Hz 语义契约

### 3.1 频率对象

| 语义对象 | 标准字段 | 当前值/写法 | 使用范围 | 禁止混用 |
|---|---|---|---|---|
| 通用交流或锁相模型 | `f0_hz` | 公式中写 \(f_0\) | Biot-Savart、DLIA、模量包络、FWHM 的通用推导 | 不在通用公式变量名中硬编码 45 或 50 |
| 电网工频 | `grid_frequency_hz` | 中国场景 50；国外文献可为 60 | 运行海缆物理背景、工频串扰 | 不等同于本文台架激励 |
| 产品工作频点 | `product_frequency_hz` | 例如 25/50/133 | 产品手册或文献原值 | 不得改写为本文实验频率 |
| 供应商谱线读数 | `vendor_psd_frequency_hz` | 50 | TMR8637 随附报告 20--30 pT/\(\sqrt{\mathrm{Hz}}\) 读数 | 不得写成本文独立 50 Hz 实测 |
| 本文电缆/注入激励 | `excitation_hz` | 45 | 既有联合实验、M4--M6、R28 | 背景空载记录应为 `null`，不得虚构激励 |
| DLIA 解调参考 | `reference_hz` | 既有分析和后续主实验为 45 | I/Q、幅值、相位、SNR、检测概率 | 不得从软件默认配置反推 |
| 频偏扫描 | `sweep_frequency_hz` | 44--46 | M7 与频偏鲁棒性 | 每个 run 仍须保存实际 `excitation_hz` 和 `reference_hz` |
| ADC 原始采样率 | `sample_rate_hz` | 名义 2000 | TMR/SK2301 原始采集 | 不得称为 DLIA 更新率或有效采样率 |

### 3.2 每个磁实验必须记录的字段

| 字段 | 类型 | 必需 | 含义 | 旧数据缺失时 |
|---|---|---:|---|---|
| `data_source_id` | string | 是 | 原始记录 ID、供应商报告 ID 或仿真 run ID | 不得只写“实测数据” |
| `data_layer` | enum | 是 | `vendor_document`、`sensor_raw`、`offline_analysis`、`simulation`、`platform_hardware`、`metrology_rig` | 无法判定则不进入主结果表 |
| `excitation_hz` | number/null | 是 | 物理注入或电缆电流频率；空载背景为 `null` | 可从独立实验日志恢复，否则标 `unknown` |
| `reference_hz` | number/null | 是 | DLIA 实际解调参考；未做解调为 `null` | 可从结果摘要恢复；不能从当前默认配置推断 |
| `frequency_source` | enum | 是 | `recorded_metadata`、`hardware_reference`、`analysis_config`、`vendor_curve`、`literature`、`legacy_inference` | 使用 `legacy_inference` 时必须给证据路径 |
| `reference_type` | enum/null | 是 | `software`、`external_current`、`mains` 或 `null` | 旧记录不明则写 `unknown` |
| `sample_rate_hz` | number/null | 原始数据必需 | ADC 名义采样率 | 同时保留有效采样率审计字段 |
| `window_sec` / `hop_sec` | number/null | DLIA 必需 | 锁相窗口与步长 | 缺失则不得比较分位数 |
| `window_name` | string/null | DLIA 必需 | `rect`、`hann`、`blackmanharris` 等 | 旧 `compute_lockin` 明确记为 `rect` |
| `enbw_hz` | number/null | 噪声结论必需 | 实际处理链等效噪声带宽 | 未计算时不能外推 0.05 nT |
| `frequency_provenance` | string | 是 | 支撑上述频率字段的文件与字段位置 | 至少一个可读路径 |

### 3.3 当前频率证据登记

| 数据/配置 | `excitation_hz` | `reference_hz` | 来源强度 | 结论 |
|---|---:|---:|---|---|
| `raw_data/1783235358_205719.npz` | NPZ 内缺失 | NPZ 内缺失 | 原始包只含采样率、通道、时间戳、灵敏度与标定 | 不能仅凭 NPZ 判断频率 |
| `joint_analysis/.../fit_summary.json` | 45 | 45 | `constants.lockin_frequency_hz=45.0`，并有已知注入电流与联合报告 | 联合拟合可明确写 45 Hz |
| `raw_data/1780675809_291477.npz` | `null` | NPZ 内缺失 | 空载原始包无频率字段；现有分析脚本固定 45 | 只能写“按 45 Hz 离线复核”，频率来源为 `legacy_inference` |
| `scripts/analyze_recording.py` | 不定义 | 45 | `LOCKIN_FREQUENCY_HZ=45` | 证明分析配置，不证明原始采集时配置 |
| `config/default_config.yaml` / `user_config.yaml` | 不定义 | 默认 50 | 当前 GUI/DSP 软件默认值 | 只说明默认配置，不能覆盖 45 Hz 结果摘要 |
| `core/lockin.py` 与 50 Hz 单元测试 | 合成 50 | 50 | 算法默认值和通用性测试 | 证明函数可处理 50 Hz，不是本文实测证据 |
| TMR8637 编号 6\# 随附报告 | 不适用 | 不适用 | 供应商纸质谱线在 50 Hz 的读数 | 字段使用 `vendor_psd_frequency_hz=50` |

由此确定优先级：机器可读结果摘要优先于当前默认配置；原始包若未保存频率，必须
显式降低 provenance，不允许用代码现状回填历史事实。

## 4. 图表与结果字段边界

### 4.1 图表最小标注

| 图表类型 | 必须在图注/表注出现 | 可省略条件 |
|---|---|---|
| 供应商 PSD | 数据来源、`vendor_psd_frequency_hz=50`、非本文独立复测 | `excitation_hz`、`reference_hz` 写“不适用” |
| 背景噪声 ASD/FFT | 记录 ID、`excitation_hz=null`、分析目标频率或频带、窗函数、时长 | 未做 DLIA 时 `reference_hz=null` |
| DLIA I/Q/幅相 | 记录 ID、`excitation_hz`、`reference_hz`、参考类型、窗口/步长、窗函数 | 不得省略频率来源 |
| 电缆+ArUco 联合拟合 | 记录 ID、45 Hz 激励/参考、样本数/对齐点、位姿来源、模型 | 不得只写“工频实测” |
| 频偏扫描 | 每档实际激励/参考、扫描范围、频率步长、同步方式 | 不得只在标题写 44--46 Hz |
| 通用模型示意 | 使用 \(f_0\)，注明与具体实验频率无关 | 不写 `excitation_hz` |
