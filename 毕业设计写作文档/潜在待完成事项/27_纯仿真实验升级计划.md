## 1. 统一实验数据结构（对齐用户第七节，但不推翻现有契约）

现有已有 `tools/experiment_contract.py` 的标准 bundle（`run_manifest.json / status.json / config_snapshot/ / metrics.csv / failure_events.csv / environment.txt / figures/ / report.md`）。用户建议的 `results/sim_<ts>_<scenario>/{config.yaml,metrics.json,trajectory.csv,...}` 与之**大体等价但字段更细**。

**决策：不新造并行标准，扩展现有契约**：
- 保留 `experiment_contract` bundle 为权威；
- **新增可选导出器** `tools/export_sim_run_tables.py`：从现有 MCAP/metrics 派生用户要的 `trajectory.csv / estimator.csv / controller.csv / behavior_tree.csv / sensor_status.csv / events.csv / metrics.json`，落到 `results/<exp>/<run>/tables/`，**不改** sweep 主流程；
- 字段按用户第七节（cross_track_error、covariance_trace、nis、nees、solve_time_ms、bt state/trigger/recovery_mode 等）。缺列（如 nees）在实现后回填，未实现前写 `not_observed`（沿用 R04 契约）。

> 硬约束：所有新驱动用**专用配置**，不污染 CBF/R22 主线；A/B 对照不回改 `es_ekf.py`/`params.yaml` 默认（记忆约束）。

## 2. 组 A：基准巡检任务实验（收尾成套）

- **目标**：理想/轻噪声下完成"搜索→捕获→沿线跟踪"闭环，PID/普通 MPC/UA-MPC 三控制器对比。
- **复用**：`run_thesis_sweep.py`（baseline 场景）+ `mpc_xy_yaw_extreme_benchmark.py`（三控制器公平多种子）。
- **缺口最小实现**：
  1. 用 `export_sim_run_tables.py` 从 baseline 运行导出 trajectory/estimator/controller/bt 表；
  2. 新增 `tools/plot_baseline_patrol_figures.py`：出**7 图**——轨迹 vs 海缆、横向误差-t、航向误差-t、控制输入-t、BT 状态时间线、EKF 协方差-t、控制器对比表。
- **指标**（多已在 `aggregate_control_metrics.py`）：横向误差均值/RMSE/最大、航向误差、捕获时间、完成率、控制平滑度、饱和次数、solve p50/p95、BT 切换次数。
- **输出**：`results/sim_baseline_patrol/` + `docs/thesis/figures/chapter5/fig_5_2_*`。
- **叙述边界**：单/少种子基准只作"闭环可完成"证据，统计优劣看组 B。

## 3. 组 B：感知不确定性消融（补 NEES + 修空 runner）

- **目标**：证明 UA-MPC 引入不确定性有价值，非普通 MPC 改名。
- **对比**：PID / 普通 MPC / 固定权重 MPC / UA-MPC(代价) / UA-MPC(速度规划) / UA-MPC(代价+安全约束)。现有 `mpc_uampc_maneuver_ablation.py` 的 VARIANTS（A0/A1/A2/A3）已覆盖主要机制轴，**扩展**而非新建。
- **扰动**：低/中/高噪声、磁弱化、声呐间歇、DVL 短失效、mag dropout、海流、延迟——**全部已有 `scenarios/*.yaml` + `mock_amd_chaos.py`** 支持，直接组合。
- **缺口最小实现**：
  1. **补 NEES**：需真值轨迹；在 `uncertainty_metrics.py` 增 NEES（有 truth 时算，否则 `not_observed`），与现有 NIS 并列；
  2. **重建 `run_es_ekf_covariance_ab.py`**（现 0 字节）：按记忆中三臂（A_baseline / B_per_source_gating / C_per_source_tuned）重写驱动，使 `covariance_ab_*` 产物**可复算**（当前产物无驱动=provenance gap，答辩风险）；补写 `covariance_ab/_SOURCE.md`（现为 20 字节 stub）。
- **指标**：跟踪 RMSE、最大偏差、目标丢失次数、重捕获时间、安全违规、降速次数、控制能耗、完成率、平均耗时、失败率。
- **输出总表**：`方法 × 噪声等级` 大表 + 三关键图（RMSE 柱状、不确定性↑时航速/搜索幅度变化、UA-MPC vs MPC 目标丢失轨迹对比）。
- **边界**：per_source 门控下 DVL 过保守是**结构性下界**（自适应仅膨胀），如实承认（已入记忆/§5.6）。

## 4. 组 C：声磁协同融合消融（本轮最大实验缺口）

- **目标**：声磁协同 > 单模态 / 简单拼接。
- **对比配置**：①IMU+DVL ②+磁 ③+侧扫声呐 ④+磁+声呐 ⑤声磁融合固定协方差 ⑥声磁融合自适应协方差。
- **现状缺口**：无单驱动跑 on-off 组合矩阵；声呐仅噪声尺度非量测。
- **最小实现（不过度工程化）**：
  1. 新增 `tools/run_fusion_ablation.py`：以 CLI/专用 yaml 开关 `enable_dvl/enable_mag/enable_sonar` 与 `adaptive_r_mode`，复用 `offline_ekf_benchmark` 引擎，同 Bag 同源重算；
  2. 声呐**先以现有感知噪声尺度参与**（诚实标注"声呐作为感知置信度输入而非独立 EKF 量测"），不为此重写观测模型（避免过度工程化）；若时间允许再评估把声呐横偏作为弱量测。
- **场景**：浅埋/裸露/声呐短时不可见/磁弱/电磁噪声增强/缆距变化/地形起伏——复用 `scenario_mag_distortion_*`、`scenario_sonar_clutter`、combined。
- **指标**：横向位置估计误差、埋深/等效深度误差、状态 RMSE、协方差一致性（NIS/NEES）、目标丢失率、重捕获成功率。
- **图**：组合定位误差对比、声呐失效期磁接力、磁弱信号融合误差、EKF 残差/协方差、自适应 vs 固定 R。
- **边界**：声呐非独立量测这一简化必须写明；埋深反演仍基于直导线/公共复尺度（[03](file:///home/auv_user/auv_ws/AUV-Master-Project/毕业设计写作文档/潜在待完成事项/03_现有实验基础设施探查.md) §3.3）。

- **目标**：BT 安全调度在故障下真起作用，非流程图。

- **缺口最小实现**：

  2. **导出 BT 状态时间线 CSV**（现只出 PNG）：`behavior_tree.csv`（time,state,previous_state,trigger,confidence,fault_type,recovery_mode），供图与追溯；
  3. 行为模式对齐用户命名：SEARCH_ZIGZAG / CABLE_CAPTURE / PARALLEL_TRACKING / RELOCALIZATION / SAFE_HOVER / RETURN_OR_ABORT / DEGRADED_MODE（映射现有 behaviors）。
- **指标**：故障检测时间、切换时间、重捕获成功率、平均恢复时间、安全模式触发次数、任务失败率、误触发/漏触发次数。

## 8. 统一门禁与写作原则

- 每个新驱动：专用 yaml、`experiment_contract` bundle、`--seeds` 支持、失败运行计入 `failure_events.csv`。
- 每张论文图：可追溯到脚本 + 数据文件，写入 `chapter5_figures_index.md` 与 Artifact Manifest。
- 结论写作：只写实跑结果；多种子报均值±std；单次≠规律；不理想如实归因；未验证写"尚未验证"；理想条件写边界；配置全保存。
- A/B 不回改主线默认（记忆约束）；如需回写默认须单独批准并重跑 24 矩阵（不在本轮）。
