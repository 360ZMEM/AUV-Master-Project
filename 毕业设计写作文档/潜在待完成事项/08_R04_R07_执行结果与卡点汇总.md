## 2. R04 实验 bundle 契约

### 2.1 代码与接入

- `tools/experiment_contract.py`：初始化、结束、校验统一实验 bundle；
- `tools/validate_experiment_bundle.py`：命令行门控，不完整诊断返回非零；
- `tools/run_thesis_sweep.py`：保留旧 `manifest.json/results.csv`，新增标准产物；
- `tools/run_proxy_cable_sweep.py`：同样接入，并新增 `--dry-run`；
- `tests/test_experiment_contract.py`：覆盖“字段显式缺失”和“诊断完整”两种状态。

每个新 bundle 包含：

```text
run_manifest.json
config_snapshot/
metrics.csv
status.json
failure_events.csv
environment.txt
report.md
figures/
```

`run_manifest.json` 保存当前主仓和子模块 commit、实验矩阵、runner、argv、数据层级、
配置快照路径与 SHA256。全仓 dirty 状态因当前环境缺 `git-lfs` 不做伪检测，
状态明确写 `not_evaluated`。

### 2.2 严格门控

`metrics.csv` 固定包含：

- `valid_run`、`invalid_reason`；
- `effective_sample_count`；
- `failure_event_count`；
- `capability_gate_status`；
- `solver_wall_time_current_ms`；
- `fallback_type`。

字段存在不等于证据存在。若 runner 尚不能观测该量，必须写 `not_observed`；
`status.json.contract_complete=false`。因此旧的“退出码为 0 + 有 MCAP”只能判运行
有效，不能判诊断完整。R04 dry-run 的两个 bundle 均正确触发这一不完整状态。

### 3.2 24 包结果

来源为 8 场景 × 3 seed 的 24 个 MCAP，共 35243 个标准 NIS 更新事件。
下表是 8 个场景的场景级均值再平均，用于显示量级，不替代逐场景 CSV：

| 观测源 | 自由度 | NIS/自由度均值 | 双侧 95% 带覆盖率 | 上界超限率 |
|---|---:|---:|---:|---:|
| Depth | 1 | 7.166 | 56.33% | 41.32% |
| DVL world | 3 | 0.117 | 54.75% | 0% |

该结果不是“总体 NIS 约 3--4，因此一致”的证据，而是两个方向相反的失配：

- 深度观测 NIS 显著偏高，当前深度测量噪声/模型不确定性被低估；
- DVL NIS 显著偏低，当前 DVL 噪声或状态协方差过于保守；
- 两类原始 NIS 混合后可能得到看似中等的均值，但该均值没有单一自由度。

### 3.3 可写与不可写

可以写：

> 自适应 R 在历史运行中发生过操作性触发；按观测源拆分后，深度与 DVL 的
> NIS 呈现相反失配，说明需要按观测维数归一化并分别整定。

不可以写：

> 当前 `nis_threshold=9.0` 是统一的 95% 卡方阈值，且历史触发证明滤波一致。

原因是 `algorithm/es_ekf.py` 当前在同一滑窗内混合 3 维 DVL 与 1 维深度原始
NIS，再把均值与固定阈值 9.0 比较。R05 只修复分析与证据语义，没有偷偷改动
滤波算法，从而保留历史实验可解释性。

## 4. R06 无头 45 Hz 分析器

入口：

```bash
python3 tools/analyze_tmr_recording.py INPUT.npz \
  --output-dir OUTPUT \
  --frequency 45 \
  --window hann \
  --window-sec 1 \
  --hop-sec 0.05 \
  --detrend linear
```

实现内容：

- `rect`、`hann`、`blackmanharris`；
- 常数/线性去趋势；
- 可选整段 FFT 频带限制；
- 相干增益与 ENBW；
- 使用全局采样时间的连续 I/Q，避免滑窗局部相位重启；
- 三轴幅相、向量幅值、ASD、p50/p95/p99 与阈值超限率；
- R03 的 `excitation_hz`、`reference_hz`、来源与 provenance；
- `analysis_summary.json`、`lockin_timeseries.csv`、`spectrum.csv` 和双格式图。

分析器不依赖 GUI 或 PySide6。SciPy 只为恢复的联合几何优化脚本使用，基础
45 Hz 分析器仍只依赖 NumPy 与 Matplotlib。

## 5. R07 45 Hz 重分析

### 5.1 短背景

1 s 窗、0.05 s 步长，共 59 窗：

| 处理 | 向量 p95 (nT) | 向量 p99 (nT) |
|---|---:|---:|
| 矩形窗 | 2.188 | 2.301 |
| Hann + 线性去趋势 | 0.372 | 0.398 |
| Blackman-Harris + 线性去趋势 | 0.419 | 0.461 |
| Hann + 40--50 Hz 离线频带限制 | 0.392 | 0.424 |

Hann 相对矩形窗使 p95/p99 下降约 83.0%/82.7%，窗泄漏归因成立。频带限制没有
继续稳定降低向量 p99，剩余量不是简单频带外宽带噪声。Hann p99=0.398 nT 仍
高于 0.05 nT，因此这是“负结果已归因但系统指标仍未达到”。

### 5.2 电缆+ArUco

- 原始记录生成 1049 个窗口；
- 以背景 Hann p99=0.398 nT 作短记录阈值，1049/1049 窗超过阈值；
- 777 个 ArUco 有效时间戳全部精确匹配；
- 新旧复 I/Q 合并 RMSE 为 \(7.05\times10^{-13}\) μT，\(R^2=1\)；
- 恢复原始联合脚本后重新执行几何优化，关键量均在 \(10^{-9}\) 容差内复现：

| 指标 | 历史 | 本次重跑 |
|---|---:|---:|
| 自由复尺度 \(R^2\) | 0.879241830652 | 0.879241830656 |
| 固定峰值电流 \(R^2\) | 0.871137270241 | 0.871137270226 |
| 等效峰值电流 (A) | 2.878878077485 | 2.878878077813 |
| 合成闭环 \(R^2\) | 0.999987803725 | 0.999987803725 |

联合脚本从同一工作区的独立 `fangkong_adc` 检出恢复；该检出中的历史
`fit_summary.json` 与当前历史摘要 SHA256 完全一致，证明脚本与现有结果同源。
但脚本没有进入当时记录的 Git commit，因此 Artifact Manifest 仍保持 B 级
provenance，不把本次恢复冒充历史版本记录。
