## 2. 分流原则

| 类型 | 处理方式 | 理由 |
|---|---|---|
| 状态量、控制量、权重和约束 | 转为 `\(...\)` 或 `equation` | 属于数学对象 |
| 样本量 \(n\)、总体次数 \(N\) | 转为数学模式 | 属于统计变量 |
| RMSE、CEP 等带下标指标 | 使用 `\operatorname{}` 和数学下标 | 避免程序字段式拼写 |
| 行为树函数名 | 从出版表格删除，仅保留中文功能 | 代码函数名无独立学术贡献 |
| 程序状态词 | 改为等价学术中文 | 不保留日志式字面量 |
| `cmd`、`ref` 等数学下标 | 使用正体下标 `\mathrm{}` | 表示语义标签而非变量乘积 |

## 3. 主要转换

状态变量：

```latex
\((x,y)\), \(z\), \(\psi\), \(u\), \(w\), \(\theta\)
```

UA-MPC 跟踪权重：

```latex
\rho(c)=(1-c)^\alpha,
\qquad
w_e(c)=w_{e,0}\left[1+s_e\rho(c)\right]
```

控制代价缩放：

```latex
\sigma(x)=\frac{1}{1+\exp(-x)},
\qquad
s_u(c)=\gamma_u+(1-\gamma_u)\sigma\!\left(k(c-c_0)\right)
```

硬约束和扩展约束统一采用标准数学形式，例如：

```latex
\(u_k\ge u_{\min}\)
\(\lvert z_{\mathrm{cmd},k+1}-z_{\mathrm{cmd},k}\rvert
  \le\Delta z_{\max}\)
```

指标名称转换为：

```latex
\(\operatorname{RMSE}_{xy}\)
\(\operatorname{RMSE}_{z}\)
\(\operatorname{CEP}_{50}\)
```

图题、表格和正文中的 `n=1`、`n=3`、`N=100` 分别转换为 \(n=1\)、\(n=3\)、\(N=100\)。

## 4. 实现语义复核

符号统一过程中复核了实际 MPC 实现。源码表明低置信度时控制代价缩放因子由 1 平滑降低到 0.3，即减小控制努力惩罚，为必要纠偏保留控制权威。

原正文将该机制解释为“施加更大惩罚、输出更平滑”，与公式和源码相反。本次按实际实现修正为：

- 跟踪权重随低置信度增大；
- 控制努力惩罚平滑降低，为纠偏保留控制权威；
- 指令平滑性由速率约束和带宽约束保证。

该修正只作用于 LaTeX 出版视图，不修改算法源码或 canonical Markdown。
