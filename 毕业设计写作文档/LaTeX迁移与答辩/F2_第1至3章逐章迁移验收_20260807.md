## 2. 可复现命令

```bash
python3 tools/migrate_thesis_chapters.py
python3 tools/migrate_thesis_chapters.py --check
python3 tools/sync_latex_references.py --check

cd thuthesis
gtimeout 240 make auv-thesis
make clean-auv-thesis
```

生成器负责：

1. 截断章末重复文献装配段；
2. 把 Markdown 手工编号标题映射为 LaTeX 自动编号标题；
3. 生成稳定的 section、figure 和 table 标签；
4. 合并图片、caption 和 label，并统一 `docs/thesis/figures/` 相对路径；
5. 为全部 Markdown 表补齐 caption 和 label；
6. 把长路径转换为可断行的 `\path{}`，把数学集合表达式转为数学模式；
7. 保留引用键、公式、正文和证据边界。
