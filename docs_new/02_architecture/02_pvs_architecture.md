# PVS 后端架构详解

本文档详细介绍 PVS (Python Vehicle Simulator) 仿真后端的架构设计、工作原理和使用方法。

## 什么是 PVS？

PVS 是一个轻量级的纯 Python AUV 仿真器，专为算法开发、CI/CD 和容器环境设计。

### 核心特性

- ✅ **纯 Python 实现**：无图形依赖，跨平台兼容
- ✅ **Headless 友好**：在容器/服务器环境完美运行
- ✅ **内置控制器**：级联 PID 控制器
- ✅ **轨迹生成**：多种轨迹类型（直线、电缆、S 形等）
- ✅ **协议兼容**：支持 Zenoh JSON 和 Protocol UDP
- ✅ **Mock AMD 集成**：完整的硬件模拟

## 核心模块详解

### 1. PVS 仿真包装器 (pvs_sim_wrapper.py)

这是 PVS 后端的核心模块。

#### 主要功能

```python
class PVSSimWrapper:
    def __init__(self, config):
        # 初始化仿真状态
        # 加载配置参数
        # 设置控制器

    def reset(self):
        """重置仿真到初始状态"""
        # 位置、速度、姿态清零

    def step(self, cmd):
        """推进一帧仿真"""
        # 1. 应用控制指令
        # 2. 执行物理更新
        # 3. 生成传感器数据
        # 4. 返回状态
```

#### 控制模式

PVS 支持多种控制模式：

| 控制模式 | 说明 | 使用场景 |
|---------|------|---------|
| `depthHeadingAutopilot` | 深度/航向自动驾驶模式 | 正常仿真、算法测试 |
| `stepInput` | 阶跃输入模式 | 硬件对接、协议测试 |

#### 物理模型

PVS内置简化的AUV物理模型：

```python
# PVS物理模型特点
- 前进速度控制
- 深度控制
- 航向控制
- 横摇/纵摇稳定性
- 简化的水动力学
```

### 2. 级联 PID 控制器

PVS内置级联PID控制器架构：

```
外环 (深度控制):
  目标深度 → PID → 目标俯仰角

内环 (姿态控制):
  目标俯仰角 → PID → 艏舵/艉舵
  目标航向角 → PID → 左舵/右舵

速度环:
  目标速度 → PID → 主电机推力
```

### 3. Mock AMD 服务器

Mock AMD（AUV Management Device）是PVS的关键组件，它模拟真实的AUV硬件通信协议。

#### Mock AMD 的主要功能

1. **协议转换**
   - Zenoh JSON ↔ 二进制 $CKTH/$AUV 协议
   - UDP 通信服务器

2. **延迟和抖动模拟**
   - 模拟真实通信延迟
   - 可配置的延迟队列
   - 抖动注入

3. **传感器故障注入**
   - IMU漂移
   - DVL冻结
   - 深度脉冲
   - 磁力计饱和
   - 数据包丢包/重排序

4. **传感器缓存**
   - 模拟多速率传感器采样
   - IMU高频更新
   - DVL低频更新

## PVS 工作流程

### 完整数据流

```
启动初始化
    ↓
加载配置 (sim_params.pvs.yaml)
    ↓
初始化物理状态
    ↓
┌─────────────────────────┐
│     主循环开始          │
└─────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 1. 接收控制指令                     │
│   - Zenoh JSON 或 UDP协议          │
│   - 应用安全限幅                    │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 2. 推进仿真一步                     │
│   - 执行物理模型                    │
│   - 更新位置、速度、姿态            │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 3. 生成传感器数据                   │
│   - IMU (姿态、角速度)             │
│   - DVL (速度)                     │
│   - Depth (深度)                   │
│   - 磁力计 (可选)                  │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 4. 应用故障注入 (可选)              │
│   - 传感器故障                     │
│   - 通信故障                       │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 5. 发布传感器数据                   │
│   - 通过 Zenoh JSON                │
│   - 或通过 Protocol UDP            │
└─────────────────────────────────────┘
    ↓
检查终止条件 → 循环继续
```

## PVS 配置详解

PVS的主要配置文件是 `config/sim_params.pvs.yaml`。

### 配置结构

```yaml
# PVS 配置示例

stage:
  name: auv_project_new_stack_pvs

simulation:
  backend: pvs
  world: Dam
  ticks_per_sec: 30
  max_steps: 6000

agent:
  type: TorpedoAUV
  control_scheme: 0
  location: [0.0, 0.0, -12.0]

control:
  target_u: 1.1
  depth:
    kp: 0.30
    ki: 0.01
  yaw:
    kp: 9.0
    ki: 0.12

pvs:
  control_mode: depthHeadingAutopilot
  initial_depth_m: 12.0
  initial_speed_mps: 0.5
```

### 关键参数说明

| 参数分类 | 关键参数 | 说明 |
|---------|---------|------|
| **simulation** | `ticks_per_sec` | 仿真频率（Hz） |
| | `max_steps` | 最大步数（0为无限） |
| **control** | `target_u` | 目标前进速度（m/s） |
| | `depth/kp` | 深度环P增益 |
| | `yaw/kp` | 航向环P增益 |
| **pvs** | `control_mode` | 控制模式选择 |
| | `initial_depth_m` | 初始深度（米） |

## 仿真后端对比总结

让我们对比两个仿真后端的详细区别：

| 维度 | PVS | HoloOcean |
|------|-----|-----------|
| **实现语言** | 纯Python | C++/UE4 |
| **图形依赖** | 无 | 需要OpenGL/Vulkan |
| **容器友好** | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| **启动速度** | 快 | 较慢 |
| **物理保真度** | 中等 | 高 |
| **3D可视化** | 无（但可用Foxglove） | 有（UE4渲染） |
| **传感器模型** | 简化 | 高保真 |
| **适用场景** | 算法开发、CI/CD、长期测试 | 可视化演示、传感器仿真 |
