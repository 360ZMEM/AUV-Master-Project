# 项目简介

## 什么是 AUV 联合开发平台？

AUV（自主水下航行器）联合开发平台是一个统一了仿真侧与决策侧的完整开发环境，旨在解决传统开发中仿真与决策系统分离、难以联调的问题。

## 核心特点

### 1. 统一仓库
- **仿真侧**：HoloOcean 高保真物理仿真
- **决策侧**：ROS2 Humble 决策控制系统
- **共享层**：统一的数据契约与协议定义

### 2. 分层架构
```
┌─────────────────────────────────────┐
│      brain_linux (决策层)            │
│   ROS2 节点：定位/控制/决策          │
└──────────────┬──────────────────────┘
               │ Zenoh/UDP 通信
┌──────────────┴──────────────────────┐
│         common (契约层)              │
│    统一协议、枚举、物理常量          │
└──────────────┬──────────────────────┘
               │
┌──────────────┴──────────────────────┐
│   sim_holoocean (仿真层)            │
│   HoloOcean + Zenoh 桥接            │
└─────────────────────────────────────┘
```

### 3. 核心原则
1. **先统一数据契约** - 所有模块使用同一套数据定义
2. **再统一启动方式** - 一键启动完整系统
3. **最后统一联调流程** - 标准化的测试与验证

## 解决的问题

### 传统开发的痛点
- ❌ 仿真与决策系统代码分离，难以管理
- ❌ 数据格式不一致，联调困难
- ❌ 启动流程复杂，新手难以入门
- ❌ 缺少统一的数据契约，容易出错

### 本平台的解决方案
- ✅ 统一仓库管理所有代码
- ✅ `common/` 目录定义单一真值源
- ✅ 一键启动脚本简化操作
- ✅ 自动化的数据校验机制

## 系统能做什么

### 仿真功能
- 高保真水下动力学仿真
- 多传感器仿真（IMU、DVL、深度计、磁力计等）
- 电缆磁场仿真与巡检任务
- 可配置的海洋环境

### 决策功能
- ES-EKF 状态估计
- PID 控制器
- 行为树决策系统
- 轨迹跟踪与导引

### 可视化功能
- Foxglove 实时数据可视化
- 三维轨迹显示
- 传感器数据监控
- 控制指令可视化

## 适用场景

1. **算法开发**：在不接触硬件的情况下开发与测试算法
2. **系统集成**：验证软硬件协同工作的正确性
3. **教学培训**：为新手提供完整的学习环境
4. **故障复现**：在仿真中复现和分析实际问题

## 项目结构概览

```
AUV_Master_Project/
├── common/           # 📦 双端共享契约（单一数据源）
├── algorithm/        # 🧮 环境无关算法
├── config/           # ⚙️ 仿真、桥接、仲裁器配置
├── sim_holoocean/    # 🌊 HoloOcean 仿真 + Zenoh 桥接
├── brain_linux/      # 🧠 ROS2 Humble 决策工作区
├── scripts/          # 🚀 统一启动脚本
├── foxglove_layout_project/  # 📊 Foxglove 可视化布局
└── docs/             # 📖 详细技术文档
```
