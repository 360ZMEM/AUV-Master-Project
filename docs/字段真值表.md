# AUV_Master_Project 字段真值表

> 目标：统一仿真侧、桥接层、ROS2 侧对字段、类型、单位和来源的理解。
>
> 说明：当前表以已落地的 `common/`、`sim_holoocean/` 和 `brain_linux/` 为基准；后续若 `auv_bridge` 正式实现，可继续追加 DDS/Zenoh 适配列。

## 1. 总体规则
- `common/protocol.py` 是字段与 topic 的单一真值源。
- `common/enums.py` 是状态与故障语义的单一真值源。
- `common/physics.py` 是物理常量与限幅的单一真值源。
- 仿真侧发布前必须经过字段与类型校验。
- 决策侧消费后必须尽量保留原始语义，不在 UI 层偷偷改名。

## 10. control command 字段

### 10.1 统一输入形式
控制输入允许三种等价格式：
- `{"command": [right, top, left, bottom, thrust]}`
- `{"right": ..., "top": ..., "left": ..., "bottom": ..., "thrust": ...}`
- `[right, top, left, bottom, thrust]`

### 10.2 归一化后的标准字段

| 字段名 | 类型 | 单位 | 来源 | 说明 |
|---|---|---|---|---|
| `right` | float | deg | brain_linux | 右舵/右侧舵面输入 |
| `top` | float | deg | brain_linux | 上舵/俯仰相关输入 |
| `left` | float | deg | brain_linux | 左舵/左侧舵面输入 |
| `bottom` | float | deg | brain_linux | 下舵/偏航相关输入 |
| `thrust` | float | % | brain_linux | 推力百分比 |

### 10.3 限幅规则
- `thrust` 归一化后限制在 `[-100, 100]`
- 舵角归一化后限制在 `[-MAX_RUDDER_DEG, MAX_RUDDER_DEG]`
- 默认 `MAX_RUDDER_DEG = 45.0`
- 兼容历史仿真默认值 `SIM_DEFAULT_MAX_RUDDER_DEG = 30.0`

## 13. 当前映射到代码的位置
- `common/protocol.py`：topic、键名、校验函数、控制归一化
- `common/enums.py`：行为状态、故障码、漏水等级
- `common/physics.py`：物理常量、限幅函数
- `sim_holoocean/interfaces/holoocean_physics_bridge.py`：上行字段实际打包
- `sim_holoocean/behavior/command_guard.py`：下行控制命令边界保护
- `brain_linux/src/auv_interfaces`：ROS2 消息定义入口

## 14. 使用建议
以后如果要改字段，优先按下面顺序检查：
1. 先改 `common/`
2. 再改仿真侧打包逻辑
3. 再改 ROS2 消息与映射
4. 最后改可视化与文档

不要反过来只改一个子系统，否则很容易出现“字段看起来存在，但语义已经错位”的问题。
