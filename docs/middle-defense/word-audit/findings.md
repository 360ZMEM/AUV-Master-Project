没有找到中期报告专用固定栏目表、学院通知或中期报告的强制页数规定。仓库按文件名合理搜索到的中期资料主要是汇报 PPT/PDF；另有[原开题报告](../../../PPT制作/2024214397—谢冠文—开题报告文档.pdf)。该文件的 PDF 第 1 页明确写“清华大学硕士学位论文选题报告”，包含姓名、学号、导师、培养单位、学科及日期；这是历史报告实例，不能自动视为当前学院中期格式规定。

有关当前中期报告正式名称和截至日期的最终口径仍由主任务集中处理。可以形成明确标识为“硕士学位论文中期报告／中期进展报告”的报告候选，不得误用 Word 终稿封面上的“申请……硕士专业学位论文”，也不得自动加入学位论文使用授权、最终答辩委员会决议书或虚构签名。

**必须保留的限制：**

1. Word 指定的 SimSun、SimHei、仿宋和 Times New Roman 在本机不齐。`fc-match` 与实际 PDF 字体清单均已记录；LibreOffice 实际导出的主要替代字体为 Noto Serif/Sans CJK、Liberation Serif/Sans，不能将 `fc-match` 的预测当作最终字体嵌入结果。
2. `09` 实际段落明确20 pt固定行距，文档同时有312 twip（15.6 pt）网格。PDF bbox 测得首组正文行 y=210.800764、242.000764、273.200764…，间隔31.2 pt。该转换现象与网格叠加相符，但未在 Microsoft Word 做因果对照，不能宣称已确定根因或学院要求31.2 pt。
3. `10-1` 转换 PDF 有可见的英文重叠/越界。本次审查状态是“已检查并发现转换限制”，不是“该 Word 副本视觉通过”。原输入不修复、不回写；新 LaTeX 报告必须独立渲染，不能沿用其瑕疵。
4. 没有 Microsoft Word 本机渲染，因此对 Windows 原生像素一致性状态为 `NOT_RUN`。这不阻塞对明确 XML 数值、文字说明与可见布局关系的核对，但阻止声称完全像素一致。
