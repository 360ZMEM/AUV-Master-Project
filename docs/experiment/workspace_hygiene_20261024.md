# 工作区分流与发布清单（2026-10-24）

本次基线：根仓库与 `AUV-Master-Mag` 均从 2026-10-17 的 `origin/main` 接续。检查时根仓库约 1.6 万个未跟踪文件、约 2.2 GiB；其中 `patent/` 约 1.47 GiB。共享目录的权限位和旧 CRLF 规范会制造大量假改动，不能把 `git status` 原始条数当作实质更改量。

| 分类 | 处置 | 理由 |
|---|---|---|
| 权威论文 TeX/Bib、图源/脚本、被引用图、三份审阅 PDF | 提交；二进制图/PDF 走 LFS | 180 页论文、38 页两版中期报告及其来源应可在另一机器复现 |
| 中期汇报当前冻结 V4.7、答辩 Markdown、Mag 公共方法图 | 提交已有更新 | 与论文图表、证据口径同步 |

| V3/V4/V4.2/V4.5/V4.6 旧版 PPT 导出、根 PPT 大型旧文件 | 本地保留并忽略 | V4.7 已冻结；旧版本可本地查阅，无需重复上传 |

| 根目录临时 `.txt`/`.md`，包括《中期报告codex指引.md》《开发进展roadmap.md》 | 保留未跟踪，不忽略、不提交 | 用户指定的唯一可见工作区例外；后两文件从版本库删除但本地仍在 |

清理执行原则：不对专利和其他会话证据执行不可逆删除；实际清理由窄范围 `.gitignore` 与本地 Git `core.filemode=false` 消除非交付项，CRLF-only 文件以一次规范化提交解决。新增交付按用途分别暂存，提交前逐项检查文件清单、`git diff --cached --check` 与 LFS 指针。后续每个任务按根 `AGENTS.md` 进行相同分流，结束时仅容许上述根目录临时文档未跟踪。

历史审计报告中提到的 `evidence/`、`before/` 等目录现为本机缓存；另一台机器可由审计工具和摘要重放，但不能把未发布缓存当作 Git 交付物。详情以各版本 README、审计摘要和发布清单为准。
