# Mock AMD 真实性增强设计

> 将 `mock_amd_server.py` 从即时透传升级为物理缺陷注入器的详细架构设计。

---

## 1. 架构对比

```
━━━━━━━━━ 当前架构 ━━━━━━━━━
$CKTH → socket.recvfrom() → 立即解析 → 立即执行 → 读最新状态 → $AUV → sendto()

━━━━━━━━━ 目标架构 ━━━━━━━━━
$CKTH → socket.recvfrom() → [FIFO 延迟队列] → 解析 → 执行
                                           ↓
         传感器采样: IMU_clock / DVL_clock / Depth_clock / Mag_clock
                                           ↓
         [混沌注入层: profile-gated injectors]
                                           ↓
         $AUV build → [丢包/重排/棕色断电] → sendto() → [sniffer mirror]
```

## 2. 新增模块

### 2.1 `sim_holoocean/interfaces/mock_amd_delay.py` — 传输延迟队列

```python
class TransportDelayQueue:
    """FIFO 延迟队列，模拟 UDP 传输延迟与抖动。"""

    def __init__(
        self,
        base_delay_ms: float = 20.0,
        jitter_ms: float = 5.0,
        max_queue_depth: int = 64,
    ) -> None: ...

    def enqueue(self, packet: bytes, recv_ts: float) -> None:
        """将收到的包放入队列，计算释放时间戳。
        
        释放时间 = recv_ts + base_delay_ms/1000 + random(-jitter_ms, +jitter_ms)/1000
        如果队列已满，丢弃最旧的包。
        """

    def dequeue(self, now: float) -> list[tuple[bytes, float]]:
        """返回所有已到释放时间的包 [(packet, recv_ts), ...]。"""

    def peek_count(self) -> int:
        """返回队列中等待的包数量。"""
```

**配置项**:
```yaml
mock_amd:
  chaos:
    transport_delay_ms: 20.0       # 基础延迟（毫秒）
    transport_jitter_ms: 5.0       # 抖动范围 ±5ms
    transport_max_queue: 64        # 最大队列深度
```

**集成点**: `MockAmdUdpServer._poll_command_packet()` 中 `socket.recvfrom()` 之后。

### 2.2 `sim_holoocean/interfaces/mock_amd_sensor_cache.py` — 异步采样缓存

```python
@dataclass
class SensorSnapshot:
    """单次传感器快照。"""
    imu: dict | None = None    # heading_deg, pitch_deg, roll_deg
    dvl: dict | None = None    # speed_mps (前向)
    depth: dict | None = None  # depth_m
    mag: dict | None = None    # B_ned[3], B_norm
    ts: float = 0.0

class SensorSampleCache:
    """独立时钟的传感器采样缓存，模拟真实传感器不同采样率。"""

    def __init__(
        self,
        imu_hz: float = 100.0,
        dvl_hz: float = 6.0,       # 典型 DVL: 5-7 Hz
        depth_hz: float = 50.0,
        mag_hz: float = 20.0,
    ) -> None:
        self._imu_period = 1.0 / max(0.1, imu_hz)
        self._dvl_period = 1.0 / max(0.1, dvl_hz)
        self._depth_period = 1.0 / max(0.1, depth_hz)
        self._mag_period = 1.0 / max(0.1, mag_hz)
        self._last_sample: SensorSnapshot = SensorSnapshot()
        self._last_imu_ts = 0.0
        self._last_dvl_ts = 0.0
        self._last_depth_ts = 0.0
        self._last_mag_ts = 0.0

    def update(
        self,
        raw_state: dict,
        agent_name: str,
        now: float,
    ) -> SensorSnapshot:
        """根据各传感器时钟决定是否刷新缓存。
        
        只有时钟到期时才重新采样，否则返回上次缓存值。
        返回合并后的 SensorSnapshot。
        """

    def snapshot(self) -> SensorSnapshot:
        """返回当前缓存快照（构建 $AUV 时使用）。"""
```

**配置项**:
```yaml
mock_amd:
  sensor_clocks:
    imu_hz: 100.0
    dvl_hz: 6.0
    depth_hz: 50.0
    mag_hz: 20.0
```

### 2.3 `sim_holoocean/interfaces/mock_amd_chaos.py` — 混沌注入器

```python
@dataclass
class ChaosProfile:
    """混沌注入配置，每个行为独立开关。"""

    # 传输层
    enabled: bool = False               # 总开关
    packet_loss_pct: float = 0.0        # 丢包概率 0.0-1.0
    reorder_enabled: bool = False       # 是否启用乱序
    reorder_buffer_ms: float = 50.0     # 乱序缓冲时间

    # 传感器层
    dvl_freeze_enabled: bool = False    # DVL 冻结
    dvl_freeze_after_s: float = 30.0    # 运行 N 秒后触发
    imu_drift_enabled: bool = False     # IMU 漂移
    imu_drift_rate_deg_per_s: float = 0.5  # 漂移速率 °/s
    depth_spike_enabled: bool = False   # 深度跳变
    depth_spike_m: float = 5.0          # 跳变量（米）
    depth_spike_after_s: float = 60.0   # 触发时间
    mag_saturation_enabled: bool = False  # 磁饱和
    mag_saturation_threshold_t: float = 50000.0  # 饱和阈值 nT

    # 上行层
    uplink_dropout_enabled: bool = False  # 上行棕色断电
    uplink_dropout_on_pct: float = 0.8   # 断电周期占比
    uplink_dropout_period_s: float = 10.0  # 断电周期（秒）

class ChaosInjector:
    """基于 ChaosProfile 对传感器数据和上行帧进行故障注入。"""

    def __init__(self, profile: ChaosProfile, start_time: float = 0.0) -> None:
        self._profile = profile
        self._start_time = start_time
        self._dvl_frozen: dict | None = None
        self._imu_drift_accum: float = 0.0
        self._uplink_cycle_phase: float = 0.0

    def apply_to_sensors(
        self,
        snapshot: SensorSnapshot,
        elapsed_s: float,
    ) -> SensorSnapshot:
        """对传感器快照应用混沌注入，返回修改后的快照。
        
        处理顺序: DVL冻结 → IMU漂移 → 深度跳变 → 磁饱和
        """

    def should_drop_uplink(self, elapsed_s: float) -> bool:
        """根据棕色断电配置决定是否丢弃此帧。"""

    def should_reorder(self, elapsed_s: float) -> bool:
        """根据乱序配置决定是否延迟此帧。"""

    def reset(self) -> None:
        """重置所有累积状态。"""
```

## 4. 混沌注入行为详细说明

### 4.1 DVL 冻结

- **触发条件**: `dvl_freeze_after_s` 秒后开始
- **行为**: 将 DVL 速度冻结为触发时刻的最后一次有效值
- **效果**: 导航系统逐渐漂移，行为树可能切换到安全模式
- **恢复**: 无自动恢复，需要通过配置切换

### 4.2 IMU 漂移

- **触发条件**: 立即生效（如果 enabled）
- **行为**: 航向值每秒累积 `imu_drift_rate_deg_per_s` 度偏移
- **效果**: 姿态估计发散，航向控制失效
- **实现**: `heading_drift = elapsed * drift_rate`，加到缓存航向上

### 4.3 深度跳变

- **触发条件**: `depth_spike_after_s` 秒后瞬间偏移 `depth_spike_m` 米
- **行为**: 一次性深度值偏移
- **效果**: 触发深度保护，AUV 紧急上浮
- **恢复**: 跳变后保持偏移值（物理上意味着深度传感器故障）

### 4.4 磁饱和

- **触发条件**: 立即生效
- **行为**: 磁场向量各分量被截断到 `±mag_saturation_threshold_t`
- **效果**: 磁探测数据失真，电缆识别失效
- **实现**: 对 `B_ned` 每个分量做 `clamp(component, -threshold, +threshold)`

### 4.5 上行棕色断电

- **触发条件**: 周期性触发
- **行为**: 每个周期 `uplink_dropout_period_s` 中，前 `on_pct` 比例的时间不发送 $AUV 帧
- **效果**: 上位机心跳超时，触发自动重连或安全回退
- **实现**: `phase = (elapsed % period) / period; drop = phase < on_pct`

### 4.6 丢包

- **触发条件**: 每帧独立概率判断
- **行为**: 以 `packet_loss_pct` 概率丢弃上行帧
- **效果**: 链路不稳定，数据丢失
- **实现**: `random.random() < loss_pct → skip sendto()`

### 4.7 重排

- **触发条件**: 周期性触发
- **行为**: 将当前帧延迟到缓冲期之后发送，下一帧可能先发
- **效果**: 帧序号不连续，测试上位机乱序处理
- **实现**: 小概率（~5%）将帧放入延迟缓冲，正常帧立即发送
