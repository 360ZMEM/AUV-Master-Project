### $CKTH 对照：Python `protocol.py`

Python 的 `build_downlink_packet()` 字节布局与 VxWorks **完全一致**。

| 检查项 | 结果 |
|--------|------|
| Header 位置 | ✅ `packet[0:5] = PROTOCOL_DOWNLINK_HEADER` |
| 帧计数 | ✅ `packet[5] = frame_counter` |
| 舵角 27-34 | ✅ `i16 BE ×10` |
| 主电机 23-24 | ✅ `i16 BE` (RPM = thrust × scale) |
| 参数区 37-68 | ✅ `4×i32 + 8×i16` |
| 校验和 69 | ✅ `sum(packet[:69]) & 0xFF` |
| 尾部 70-71 | ✅ `0xFF 0xFF` |
