# 配置扩展方案

> 在 `config/bridge_params.protocol_udp.yaml` 中新增 `mock_amd:` 配置节，控制延迟、传感器时钟、混沌注入。

---

## 1. 当前配置结构

```yaml
# config/bridge_params.protocol_udp.yaml（现有）
protocol_udp:
  bind_port: 52364
  remote_port: 52365
  sniffer_mirror_port: 52366
  telemetry_default: {...}
```

## 2. 新增 `mock_amd:` 配置节

以下为完整 schema，所有字段均带默认值，新增后不影响现有行为。

```yaml
# ── Mock AMD 仿真器配置 ──
mock_amd:

  # 传输延迟模拟
  # > 0 时启用 FIFO 延迟队列
  transport_delay_ms: 0.0
  transport_jitter_ms: 0.0
  transport_max_queue: 64

  # 传感器独立采样率
  # > 0 时启用 SensorSampleCache
  sensor_clocks:
    imu_hz: 0.0       # 0 = 禁用（直接读最新值）
    dvl_hz: 0.0
    depth_hz: 0.0
    mag_hz: 0.0

  # 混沌注入总开关
  # false 时以下所有注入行为均不生效
  chaos:
    enabled: false

    # ── 传输层注入 ──
    packet_loss_pct: 0.0              # 丢包概率 [0.0, 1.0]
    reorder_enabled: false            # 帧乱序
    reorder_buffer_ms: 50.0           # 乱序延迟缓冲

    # ── 传感器层注入 ──
    dvl_freeze_enabled: false         # DVL 冻结
    dvl_freeze_after_s: 30.0          # 运行 N 秒后冻结

    imu_drift_enabled: false          # IMU 航向漂移
    imu_drift_rate_deg_per_s: 0.5     # 漂移速率 °/s

    depth_spike_enabled: false        # 深度突变
    depth_spike_m: 5.0                # 突变量（米）
    depth_spike_after_s: 60.0         # 触发时间

    mag_saturation_enabled: false     # 磁场饱和
    mag_saturation_threshold_t: 50000.0  # 饱和阈值（nT）

    # ── 上行层注入 ──
    uplink_dropout_enabled: false     # 上行棕色断电
    uplink_dropout_on_pct: 0.8        # 断电周期占比
    uplink_dropout_period_s: 10.0     # 断电周期（秒）
```

## 3. 配置加载逻辑

`MockAmdUdpServer.__init__()` 中加载：

```python
mock_cfg = self.config.get('mock_amd', {})

# ── 传输延迟 ──
delay_ms = mock_cfg.get('transport_delay_ms', 0.0)
jitter_ms = mock_cfg.get('transport_jitter_ms', 0.0)
max_q = mock_cfg.get('transport_max_queue', 64)
if delay_ms > 0 or jitter_ms > 0:
    self._delay_queue = TransportDelayQueue(
        base_delay_ms=delay_ms,
        jitter_ms=jitter_ms,
        max_queue_depth=max_q,
    )

# ── 传感器缓存 ──
clocks = mock_cfg.get('sensor_clocks', {})
if any(v > 0 for v in clocks.values()):
    self._sensor_cache = SensorSampleCache(
        imu_hz=clocks.get('imu_hz', 0.0) or 100.0,
        dvl_hz=clocks.get('dvl_hz', 0.0) or 6.0,
        depth_hz=clocks.get('depth_hz', 0.0) or 50.0,
        mag_hz=clocks.get('mag_hz', 0.0) or 20.0,
    )

# ── 混沌注入 ──
chaos = mock_cfg.get('chaos', {})
if chaos.get('enabled', False):
    profile = ChaosProfile(
        enabled=True,
        packet_loss_pct=chaos.get('packet_loss_pct', 0.0),
        reorder_enabled=chaos.get('reorder_enabled', False),
        reorder_buffer_ms=chaos.get('reorder_buffer_ms', 50.0),
        dvl_freeze_enabled=chaos.get('dvl_freeze_enabled', False),
        dvl_freeze_after_s=chaos.get('dvl_freeze_after_s', 30.0),
        imu_drift_enabled=chaos.get('imu_drift_enabled', False),
        imu_drift_rate_deg_per_s=chaos.get('imu_drift_rate_deg_per_s', 0.5),
        depth_spike_enabled=chaos.get('depth_spike_enabled', False),
        depth_spike_m=chaos.get('depth_spike_m', 5.0),
        depth_spike_after_s=chaos.get('depth_spike_after_s', 60.0),
        mag_saturation_enabled=chaos.get('mag_saturation_enabled', False),
        mag_saturation_threshold_t=chaos.get('mag_saturation_threshold_t', 50000.0),
        uplink_dropout_enabled=chaos.get('uplink_dropout_enabled', False),
        uplink_dropout_on_pct=chaos.get('uplink_dropout_on_pct', 0.8),
        uplink_dropout_period_s=chaos.get('uplink_dropout_period_s', 10.0),
    )
    self._chaos = ChaosInjector(profile)
```

## 4. 默认行为保证

- **所有新增配置项默认值均等效于"不启用"**
- 不在 YAML 中添加 `mock_amd:` 节 → 所有新模块不实例化 → 行为与修改前完全一致
- `chaos.enabled: false`（默认）→ 即使存在 chaos 子节，也不会实例化注入器
- 向后兼容：旧配置文件无需任何修改即可正常工作

## 5. 推荐的测试预设

### 5.1 轻度抖动（日常开发）

```yaml
mock_amd:
  transport_delay_ms: 15.0
  transport_jitter_ms: 3.0
  sensor_clocks:
    dvl_hz: 6.0
```

### 5.2 传感器故障演练

```yaml
mock_amd:
  sensor_clocks:
    dvl_hz: 6.0
  chaos:
    enabled: true
    dvl_freeze_enabled: true
    dvl_freeze_after_s: 20.0
```

### 5.3 全链路压力测试

```yaml
mock_amd:
  transport_delay_ms: 50.0
  transport_jitter_ms: 20.0
  sensor_clocks:
    imu_hz: 100.0
    dvl_hz: 6.0

    mag_hz: 20.0
  chaos:
    enabled: true
    packet_loss_pct: 0.02

    imu_drift_rate_deg_per_s: 0.3
    depth_spike_enabled: true
```
