# 第 1 章：研究背景与意义

## 1.1 研究背景与重大意义

### 1.1.1 海上风电的战略地位

海上风电正在从近海走向深远海。随着风机单机容量的不断提升、场站规模的持续扩大和离岸距离的逐步增加，海底电缆成为连接发电端、升压站和陆上电网的关键通道。在我国"双碳"目标的推动下，深远海风电被列为新能源发展的重要方向之一，其并网稳定性直接影响区域电力供应安全和可再生能源消纳能力。

论文第 1.1.1 节应围绕国家能源战略、深远海风电发展趋势和海缆基础设施的关键性展开论述。具体政策文件和统计数据需在正式写作时补充正式文献引用。

### 1.1.2 海缆——风电场的"生命线"

对于海上风电场而言，海缆不只是供电附件，而是整个场站能量外送的生命线。一旦海缆因锚损、冲刷、掩埋状态变化或自然灾害发生故障，停机损失、抢修成本和并网风险会迅速放大。行业经验表明，海缆故障导致的停电损失可达百万级别每天，且抢修窗口受海况制约，进一步放大了经济损失。

本节可以引用行业报告或运行规程中的典型故障案例，说明海缆巡检不是常规维护任务，而是保障风电场持续运营的前置条件。

### 1.1.3 运维现状与挑战

传统海缆巡检主要依赖人工、拖曳设备、ROV（遥控水下机器人）或母船作业。ROV 的优势是可操作性强、可实时干预，但通常需要母船支持、缆控连接和专业操作人员，作业成本较高且受海况影响明显。人工巡检和简化拖曳式巡检在效率、安全性和覆盖范围上存在限制，尤其在深远海环境下，母船调度和人员安全风险更加突出。

AUV（自主水下航行器）的价值在于它可以在预设任务约束下自主航行、近底扫描、持续记录多源传感数据，并在一定程度上降低母船依赖。因此，本文把 AUV 定位为"海缆巡检降本增效和无人化运维"的重要技术路径，但不过度夸大为完全替代 ROV。更合理的表述是：AUV 适合大范围、周期性、前置筛查式巡检，ROV 仍适合精细维修和确认。

## 1.2 海底管缆探测技术研究现状

### 1.2.1 声学探测技术

侧扫声呐（SSS）和浅地层剖面仪（SBP）是当前海底电缆探测中最常用的声学手段。侧扫声呐能给出较直观的海底纹理和电缆露出段的成像线索，浅地层剖面仪则能探测掩埋电缆的浅层结构。但在浑浊水域、强散射环境、底质变化剧烈或深掩埋条件下，声学成像会出现不稳定、漏检和误检。

本节应指出声学探测的核心局限：对底质和浑浊度敏感、掩埋深度超过声波穿透能力时失效、图像解译依赖人工经验。这些局限为引入多源融合提供了动机。

### 1.2.2 电磁感应探测技术

通量门磁强计（Fluxgate）和磁感应式传感器利用电缆电流产生的磁异常进行定位或埋深估计。电力行业标准对磁探测灵敏度提出了明确要求，例如《DL/T 1278-2025 海底电力电缆运行规程》中对探测精度的约束。三相交流电缆的磁场相互抵消、铠装屏蔽和导线螺旋绞合会使漏磁特征更弱、更复杂，这是区别于单芯直流电缆的关键难点。

本节应强调电磁感应的优势（不受浑浊度影响、可穿透一定掩埋层）和劣势（信号弱、易受外部干扰、三相抵消导致特征模糊）。行业标准的具体条款需在正式论文中补充原文引用。

### 1.2.3 多源感知融合技术

声学和电磁感知的融合是当前海底电缆探测的前沿方向。声学提供几何成像和路由线索，磁学提供电缆存在性和埋深估计，二者互补但融合面临挑战：时间同步不一致、空间坐标系未对齐、观测质量随环境剧烈变化、单一传感器失效时的接管逻辑缺乏鲁棒设计。

现有研究多集中在静态或理想条件下的声磁融合，缺乏在"高不确定性"环境下的鲁棒融合研究。本文的出发点之一正是把"不确定性感知"作为融合的前提，而非假设传感器始终可靠。

## 1.3 AUV 自主控制与决策系统现状

### 1.3.1 轨迹跟踪控制

AUV 轨迹跟踪控制的主流方法包括 PID、LQR 和模型预测控制（MPC）。PID 因实现简单、调参直观在工程中广泛使用，但在复杂路径、约束处理和不确定性适应方面存在局限。LQR 在线性化模型下有最优性保证，但对 AUV 这种强非线性、欠驱动系统适用性受限。MPC 能在预测时域内处理约束和优化目标，理论上更适合复杂路径跟踪和速度规划，但对模型精度和在线求解算力有较高要求。

本文的实验结果表明：在近底地形跟随任务中，调优后的 PID/PVS 是当前最可靠的方案；在复杂平面路径制导中，MPC 的预瞄和速度规划显示出潜力。因此，本文不追求"一种控制器覆盖所有任务"，而是按任务特性选择最合适的控制层级。

### 1.3.2 自主决策架构

自主决策架构中，有限状态机（FSM）和行为树（Behavior Tree, BT）是两种主流范式。FSM 的优点是状态转移明确、实现简单，但在状态数量增长后容易出现转移爆炸、可组合性差和异常处理困难。行为树通过条件节点和行动节点的层级组织，天然支持任务可组合、异常可抢占和优先级管理，更适合 AUV 巡检这种需要正常任务执行与应急自愈并存的任务。

本文采用行为树作为自主决策的核心框架，把搜索、锁定、跟踪和 failsafe 行为组织在同一个决策树中。

## 1.4 本文研究内容与核心创新点

### 1.4.1 研究内容

本文研究内容涵盖以下四个方面：

1. **面向 AUV 海缆巡检的软硬件系统集成**：构建包含执行层（AMD/VxWorks）、感知决策层（Jetson/ROS2）、上位机和仿真后端的完整架构，支持从算法开发到实物部署的渐进验证。

2. **声磁协同状态估计与不确定性量化**：在 DVL 丢包、声呐杂波和磁信号畸变共存的环境中，维持状态估计连续性，并把感知不确定性传递给控制层。

3. **近底巡检任务的决策与控制策略**：采用行为树完成任务调度，以 PID/PVS 作为近底地形跟随主控制器，并实现 guidance-level MPC 作为复杂路径预瞄和速度规划扩展方向。

4. **虚实结合实验体系下的验证与边界分析**：通过 PVS 高保真仿真、chaos 故障注入和 terrain benchmark，形成可复现的实验闭环，同时明确当前结果的边界和待补实验。

### 1.4.2 核心创新点

本文的创新点应谨慎表述，避免超出现有实验证据：

1. **构建了面向海缆巡检的声磁协同双脑架构**：将执行层与感知决策层解耦，通过轻量二进制协议和上位机授权机制实现安全闭环。

2. **设计了不确定性感知的状态估计与控制接口**：把观测质量和置信度衰减映射为状态估计权重和控制代价调节的输入。

3. **验证了 PID/PVS terrain-following 与 MPC 平面路径预瞄的适用边界**：通过地形强度消融和极端路径支线，明确不同控制层级的优势场景，而非追求单一算法的全面优势。

如果后续补齐 UA-MPC 多场景多种子结果，可进一步将"不确定性感知 MPC"提升为核心实验创新。
