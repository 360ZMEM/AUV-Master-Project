# 第 3 章：声磁协同状态估计

## 3.1 引言

### 3.1.1 水下复杂环境下感知面临的挑战

水下电缆巡检的状态估计问题不是单纯的定位问题，而是在 DVL 丢包、声呐杂波、磁信号畸变、近底地形变化和通信延迟共存时，持续给控制与决策层提供可用状态和置信度。真实海况中，单一传感器可能因环境变化短时失效：DVL 因浊水或杂草遮挡丢失底部跟踪，声呐因底质变化或多径反射出现杂波，磁场因三相抵消或外部干扰出现畸变。

这些挑战共同说明了一个核心问题：状态估计器不应假设传感器始终可靠，而应在传感器条件变化时维持状态估计连续性，并把不确定性传递给控制层。

### 3.1.2 组合导航系统总体框架设计

本文把组合导航系统写成"惯性递推 + DVL/深度/声磁观测修正 + 不确定性在线评估"的结构。预测步骤由 AUV 运动学模型或惯导递推给出，观测步骤接收 DVL 速度、深度传感器、声呐管线特征和磁场反演信息。与标准 EKF 相比，ES-EKF（误差状态 EKF）更适合处理姿态误差和小扰动状态，能够把名义状态与误差状态分开维护，避免大角度旋转时的线性化误差。

## 3.2 多源异构数据预处理与时空同步

### 3.2.1 基于 ROS2 的异步传感器时间戳对齐算法

在 ROS2 与仿真/硬件桥接链路中，不同传感器频率和延迟不同。IMU 约 100 Hz、深度约 50 Hz、磁力计约 20 Hz、DVL 仅约 6 Hz。状态估计器必须按时间戳对齐观测，避免把旧观测当成当前状态。

Mock AMD 子系统中的 `SensorSampleCache` 模块模拟了各传感器的不同采样频率：每个传感器维护独立的"最后采样时间"，每帧检查是否超过采样周期，满足条件则更新缓存值，否则返回旧值（hold）。DVL 额外模拟"底部跟踪丢失"场景。

论文中可以说明多速率采样和时间戳对齐的问题已在架构上被识别和接口化，但实际高精度时间同步（如 PTP 硬件时戳）仍需现场数据进一步补充。

### 3.2.2 传感器安装偏差角标定与补偿

空间一致性包括安装偏差角、坐标系方向和传感器杆臂补偿。磁传感器安装在长杆上时，其测量点与 AUV 参考坐标系存在位移和旋转偏差。如果不做 lever-arm 改正，磁场观测的几何关系将出现系统性误差。

| 偏差类型 | 影响 | 补偿方式 | 当前状态 |
|---|---|---|---|
| 安装位置偏差 | 磁场观测点偏移 AUV 重心 | 杆臂改正（位移向量补偿） | 待实验 |
| 安装偏差角 | 传感器坐标系与 AUV 坐标系未对齐 | 旋转矩阵补偿 | 待实验 |
| DVL 安装角 | DVL 波束方向与 AUV 体轴偏差 | 速度坐标变换 | 架构已识别 |

### 3.2.3 磁场信号的工频提取与噪声抑制

海缆磁探测的困难在于有效信号可能很弱，且会受到三相抵消、铠装屏蔽、外部电磁干扰和 AUV 自身磁噪声影响。50 Hz 工频陷波或带通处理可以作为预处理思路，但论文不能只写滤波器，还需要解释滤波结果如何影响观测协方差和后续状态更新。

当前代码库更适合支撑"接口和思路已具备"的表述，硬件磁标定和实测磁谱仍属于待补实验。

## 3.3 基于改进 EKF 的声磁协同状态估计

### 3.3.1 系统状态向量与运动学模型定义

### 3.3.2 声学观测模型：基于侧扫声呐特征的管线定位

当声呐图像中电缆边缘清晰时，声学观测可以提供横向偏移和路由几何线索。声呐观测模型的输入是声呐图像中提取的电缆边缘特征，输出是 AUV 相对于电缆的横向距离估计。

该观测模型的前提是声呐图像质量足够。在浑浊、底质变化或局部掩埋条件下，声呐特征可能不稳定甚至完全丢失，此时需要磁观测接管。

### 3.3.3 磁学观测模型：基于毕奥-萨伐尔定律的埋深反演

磁学观测模型基于毕奥-萨伐尔定律建立磁感应强度与电缆电流、观测距离和埋深之间的关系。通过测量三轴磁场分量，可以反演电缆的相对位置和埋深。

该模型的核心挑战是：三相交流电缆的磁场相互抵消使信号减弱，铠装屏蔽和螺旋绞合使磁场分布复杂化，AUV 自身磁噪声和外部干扰进一步降低信噪比。

> **表格占位符**：正式论文中需补充埋深反演的数学推导和不同埋深条件下的反演精度表。

### 3.3.4 声磁接力与动态权重分配逻辑

声磁协同的核心是"handover"和"动态权重"。当声呐图像中电缆边缘清晰时，声学观测提供横向偏移和路由几何；当电缆局部掩埋或声呐不可见时，磁观测提供电缆存在性和埋深相关线索；当 DVL 丢包或磁信号畸变时，系统需要降低对应观测权重，而不是强行融合。

动态权重分配的关键变量是观测协方差 `R`。当观测质量下降时，`R` 增大，滤波器对该观测的信任度降低，更多依赖预测步骤。当观测质量恢复时，`R` 减小，滤波器重新接受该观测的修正。

## 3.4 感知不确定性的量化度量模型

### 3.4.1 基于信噪比的观测协方差 R 在线调整

不确定性量化建议采用 NIS（Normalized Innovation Squared）、协方差时序和观测质量指标共同表达。NIS 可以反映创新是否与协方差假设一致：如果 NIS 持续超过卡方分布阈值，说明协方差假设过于乐观或观测存在系统性偏差。

自适应 `R` 的调整可以把观测质量下降转化为更保守的滤波更新。具体地，当信噪比降低或 NIS 超过阈值时，增大对应观测通道的 `R` 值，使滤波器更信任预测而非观测。

### 3.4.2 传感器失效检测与置信度衰减机制

置信度衰减机制为控制层提供"当前感知是否可靠"的输入。当某传感器持续异常（如 DVL 连续丢包、磁场持续饱和），系统将该传感器的置信度逐步衰减至接近零，并在行为树层面触发降级策略（如减速、上浮或搜索模式）。

该机制与 MPC 的 UA 变体直接耦合：感知置信度降低时，MPC 的预测代价矩阵权重随之调整，使控制器更保守。

## 3.5 仿真环境下的状态估计验证

### 3.5.1 针对 DVL 丢包的鲁棒性测试

`docs/experiment/benchmark_test_log.md` 中已有 baseline n=1 的定位对比结果（ES-EKF / Std-EKF / Raw DR），可以作为工具链可用和单次效果的证据。DVL 丢包场景通过 `scenario_dvl_dropout_{10,30,60,90}.yaml` 配置，丢包率从 10% 到 90% 逐步增加。

当前结论：baseline 工具链可用，单次对比结果表明 ES-EKF 在干净环境下优于 Std-EKF 和 Raw DR。

当前缺口：DVL dropout 多场景多 seed 的系统性鲁棒性验证仍未完成，不能给出完整的 RMSE-vs-drop_rate 曲线。

### 3.5.2 磁信号畸变下的定位精度分析

磁畸变场景通过 `scenario_mag_distortion_{light,heavy}.yaml` 配置，磁饱和阈值从 1e-6 T 收紧到 1e-8 T。该场景测试磁场观测不可靠时，状态估计是否能通过降低磁观测权重维持估计连续性。

当前结论：接口和单次验证已就绪。

当前缺口：磁畸变多 seed 结果和磁信号畸变与 DVL 丢包联合场景的验证仍未完成。
