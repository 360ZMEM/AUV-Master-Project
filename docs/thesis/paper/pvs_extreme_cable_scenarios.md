# PVS 极端电缆巡检场景设计

## 概述

当前 PVS 后端已有 9 个 YAML 场景，覆盖 baseline、DVL dropout、磁畸变、声呐杂波和 combined stress。这些场景的选择是正确的第一步，因为它们直接对应水下系统常见的不确定性来源：速度观测丢失、磁场测量不可靠、声呐成像噪声、深度毛刺、IMU 漂移和均匀海流。它们适合支撑"感知与控制鲁棒性验证"，但还不能直接等同于"海底电缆巡检完整任务验证"。

差距主要来自任务几何和观测对象。真实电缆巡检不仅是传感器变差，还包括电缆本体的路由变化、贴底/半掩埋/悬跨状态、坡面和沟槽地形、局部遮挡、声呐漏检、三相交流漏磁抵消以及近底横流。现有 chaos 场景大多在固定任务轨迹上注入传感器扰动，尚未把"电缆路径本身变难"和"声磁观测随电缆状态变化"合并进同一个闭环。

因此，论文中应把现有场景写成不确定性感知验证基础，把 terrain benchmark 写成近底安全验证，把 MPC x/y/yaw 支线写成复杂路径预瞄验证，再通过以下极端电缆巡检场景设计说明如何缩小 discrepancy。

## 现有 PVS 场景与电缆巡检的差距分析

| 维度 | 现有 9 个 PVS 场景覆盖 | 电缆巡检还需要 |
|---|---|---|
| 传感器不确定性 | DVL 丢包 4 档、磁畸变 2 档、声呐杂波 | ✓ 已覆盖 |
| 通信不确定性 | 延迟、丢包、重排序（Mock AMD） | ✓ 已覆盖 |
| 环境流场 | 0.3 m/s 均匀海流（combined） | 需要横流、剪切流、流向突变 |
| 电缆几何 | 固定直线路径 | 需要 S 弯、U 型急转、坡面横穿 |
| 地形耦合 | terrain benchmark 独立验证 | 需要地形起伏 + 电缆跟踪同时 |
| 声磁接力 | 单次验证 | 需要声呐短时不可见 + 磁接力的闭环 |
| 掩埋状态 | 无 | 需要半掩埋、全掩埋、悬跨段 |
| 三相漏磁抵消 | 无 | 需要三相交流漏磁模型注入 |

## 建议场景设计

### 场景 1：`scenario_cable_s_curve`

**真实风险**：海缆局部绕障或铺设偏移，导致路由出现短波长 S 弯。这种弯曲在绕开海底障碍物、接头盒、场站边界和局部改线区域很常见。

**AUV 路径与环境设置**：短波长 S 弯（波长 20–40 m），要求 AUV 在有限视距内连续修正航向。海流 0.2 m/s 横流，地形平坦。

**声、磁、DVL、深度观测角色**：声呐提供电缆边缘特征，DVL 提供速度估计，磁场确认电缆存在性。

| 指标 | 目标 |
|---|---|
| lateral cable offset RMSE | < 2.0 m |
| route completion | > 95% |
| yaw smoothness | < 30°/s 峰值 |

**当前状态**：MPC x/y/yaw 支线已有 `s_turn_short_wave` 离线路径，但尚未接入完整 PVS/ROS 感知闭环。需要将电缆中心线、声呐可见段和磁场观测一起建模。

### 场景 2：`scenario_cable_hairpin`

**真实风险**：U 型路由或掉头段。虽然 180 度急转在海缆中不频繁，但在绕障、接头盒和场站边界会出现大曲率路由。

**AUV 路径与环境设置**：180 度急转（最小转弯半径 15 m），测试 LOS/PID 与 MPC 预瞄边界。海流 0.1 m/s，地形平坦。

**主要指标**：

| 指标 | 目标 |
|---|---|
| max lateral error | < 3.0 m |
| yaw smoothness | < 20°/s 峰值 |
| control effort | 舵角变化率 < 2°/s |

**当前状态**：MPC x/y/yaw 支线已有 `hairpin_180deg` 离线路径，显示 MPC 在该场景下横向误差改善约 38.56%。该场景的价值是测试控制和决策系统在大曲率边界下是否平滑降速、是否过冲、是否触发安全回退。

### 场景 3：`scenario_cable_slope_crossing`

**真实风险**：电缆横穿坡面或沟槽。海缆在穿越海底斜坡时，路由方向与地形梯度方向可能交叉，使 AUV 同时面临离底高度和横向跟踪约束。

**AUV 路径与环境设置**：电缆横穿坡度 5°–15° 的坡面，地形高度变化 2–5 m。AUV 需在跟踪电缆的同时保持 3 m 恒定离底高度。

**声、磁、DVL、深度观测角色**：深度传感器和地形高度图共同决定离底高度，声呐提供电缆横向偏移，磁场辅助确认。

| 指标 | 目标 |
|---|---|
| seabed_clearance_rmse_to_3m | < 0.5 m |
| lateral cable offset RMSE | < 2.5 m |
| clearance < 1.5m ratio | < 0.01 |

**当前状态**：terrain benchmark 已证明 AUV 能保持安全离底，但还没有同时跟踪电缆中心线。该场景应把 `config/bridge_params.protocol_udp.pvs.terrain*.yaml` 与电缆中心线绑定。

### 场景 4：`scenario_cable_buried_gap`

**真实风险**：局部掩埋导致声呐不可见。海缆在某些区段被泥沙掩埋，侧扫声呐无法稳定识别电缆边缘，此时磁场观测应承担接力作用。

**AUV 路径与环境设置**：一段 30–50 m 的电缆被掩埋，声呐观测在该段完全或大部分丢失。磁场观测保留弱线索（磁饱和阈值收紧到 1e-8 T）。DVL 正常工作。

**声、磁、DVL、深度观测角色**：声呐在掩埋段不可见，磁场提供电缆存在性和大致位置；进入可见段后声呐重新接管，完成 handover。

| 指标 | 目标 |
|---|---|
| detection continuity | > 90% |
| handover success | 声→磁→声切换无漂移 > 3 m |
| buried segment lateral error | < 3.0 m |

**当前状态**：这是最贴近声磁协同逻辑的场景，能直接服务第 3 章的 handover 和第 4 章的不确定性感知控制。当前场景库中声呐杂波和磁畸变分别存在，但未与"电缆掩埋"几何合并。

### 场景 5：`scenario_cross_current_near_bottom`

**真实风险**：近底横流或流向突变。真实近底流可能存在剪切、横流和方向突变，不仅影响 AUV 轨迹，还可能造成声磁观测丢失。

**AUV 路径与环境设置**：横流 0.3–0.5 m/s 作用于急弯或坡面附近。流向可突变（如从横向变为逆向），增加轨迹偏移和传感器不稳定性。

**声、磁、DVL、深度观测角色**：横流增加 AUV 横向漂移风险，DVL 可能因浊水或杂草出现丢包，声呐可能因横流扰动出现杂波。

| 指标 | 目标 |
|---|---|
| tracking RMSE | < 2.5 m |
| control effort | 舵角和推力在约束范围内 |
| fallback rate | < 0.1 |

**当前状态**：`scenario_combined_stress.yaml` 中已有 0.3 m/s 均匀海流，但真实近底流需要剪切和方向变化。该场景应补足环境流场维度。

### 场景 6：`scenario_combined_cable_extreme`

**真实风险**：多风险叠加。最不利组合下的失效边界测试。

**AUV 路径与环境设置**：急弯（hairpin）+ 地形起伏（slope）+ DVL dropout 60% + 磁饱和（heavy）+ 声呐杂波 + 横流 0.4 m/s。

**主要指标**：

| 指标 | 目标 |
|---|---|
| route completion | > 80% |
| safety violation | 0 |
| fallback rate | < 0.2 |

**当前状态**：应作为最终压力测试，而不是第一轮就追求的主结果。论文中更合理的写法是先展示单因素，再展示 combined，避免只给一个极端场景导致无法解释性能下降来源。

## 场景与毕设章节的对应关系

| 场景 | 对应章节 | 主要服务目标 |
|---|---|---|
| `cable_s_curve` | 4.5.1 / 5.2.3 | 复杂路径制导能力验证 |
| `cable_hairpin` | 4.5.2 / 5.2.3 | 大曲率边界下的安全回退 |
| `cable_slope_crossing` | 4.5.1 / 5.2.1 | terrain + cable tracking 联合验证 |
| `cable_buried_gap` | 3.3.4 / 3.5.2 | 声磁接力和 handover 验证 |
| `cross_current_near_bottom` | 4.5.2 / 5.2.2 | 近底横流下的轨迹稳定性 |
| `combined_cable_extreme` | 4.5.2 / 5.2.3 | 多风险叠加的失效边界 |

## 与电缆巡检要求的关系

这些新增场景能缩小现有仿真与真实海缆巡检之间的差距，但仍不能完全替代实海试验。它们能覆盖路径几何、近底安全、声磁接力和环境扰动四个关键维度；不能覆盖真实底质、真实电缆结构、真实传感器安装误差和海况长期变化。因此论文中应把它们写成"面向海缆巡检的高保真仿真增强"，而不是"真实海试等价验证"。

## 最小落地路径

建议分三步逐步推进：

| 步骤 | 内容 | 依赖 |
|---|---|---|
| 第一步 | 把离线 x/y/yaw 的 S 弯和 hairpin 路径迁移为 PVS 场景配置 | 已有离线路径，仅需 YAML 封装 |
| 第二步 | 把 terrain height map 与电缆中心线绑定，形成 slope crossing | terrain benchmark 已就绪 |
| 第三步 | 加入声呐短时不可见、磁信号衰减、DVL dropout 和横流，形成 combined cable extreme | 需要 chaos 注入模块联合配置 |

每一步都应保留 baseline、单因素和组合因素，便于论文解释。例如 slope crossing 场景应先跑 terrain-only、cable-only，再跑 terrain+cable，最后加 DVL dropout 和横流。
