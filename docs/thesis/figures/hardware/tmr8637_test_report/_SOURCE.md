## 4. 50 Hz 噪声谱核验

磁场噪声谱采用双对数坐标：

- 横轴为频率，覆盖约 0.1 Hz 至 10 kHz；
- 纵轴为磁场噪声谱密度，单位为 pT/√Hz；
- 图例包含编号 6# 模组的 X、Y、Z 三轴曲线；
- 报告文字给出的频带为 0.05 Hz 至 10 kHz。

50 Hz 位于 10 Hz 与 100 Hz 两条主刻度之间。按三轴曲线线宽和照片可辨分辨率读取，该位置约为 20--30 pT/√Hz，即 \(2\times10^1\ \mathrm{pT}/\sqrt{\mathrm{Hz}}\) 量级。由于原始资料是纸质曲线照片而非可导出的数值数据，论文采用区间和量级表述；“约 20 pT/√Hz”只作为中心近似，不写成精确标定值。

## 5. 证据边界

这组资料可以证明：

1. 编号 6# TMR8637 模组三轴模拟输出、灵敏度和本底噪声已经过随附测试；
2. 目标频率 50 Hz 附近的模组本底噪声显著低于 1 Hz 处的 200 pT/√Hz；
3. 按 \(S_B(f_0)\sqrt{B_{\mathrm{ENBW}}}\) 口径，模组本体在窄带检测下具备支撑 0.05 nT 系统目标的噪声裕度。

这组资料不能证明：

1. SK2301 的有效位数、输入噪声和实际采样率已经验收；
2. 隔离电源、地环路、线缆和 AUV 自生磁场不会引入额外噪声；
3. 数字锁相放大后的等效噪声带宽与输出噪声已经实测；
4. 完整测量链或海试系统已经通过 0.05 nT 验收。
