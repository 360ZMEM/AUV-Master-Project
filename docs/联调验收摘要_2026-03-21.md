# 联调验收摘要（2026-03-21）

## 1. 目的
本摘要用于记录当前 AUV_Master_Project 的联调验收状态，确认 Linux 系统 Python 环境下的仿真桥接、ROS2 决策、定位、控制链路是否已经连通，并标出后续回归重点。

## 2. 验收范围
- 仿真侧 Zenoh 桥接
- ROS2 脑端 stack
- 传感输入话题
- 定位与控制链路
- 行为树决策输出
- 启动脚本稳定性

## 3. 验收结论
### 3.1 结论状态
- 结论：通过，主链路已打通。
- 验收层级：系统联调可运行，进入稳定性回归阶段。

### 3.2 核心证据
- 系统 Python 依赖可导入：`py_trees`、`zenoh`、`yaml`
- `start_lin_brain.sh stack` 可在 `/usr/bin/python3` 下稳定构建并启动
- `start_lin_sim.sh bridge` 可输出传感采样日志
- ROS2 侧可观测到以下关键话题：
  - `/auv/sensors/imu`
  - `/auv/sensors/dvl`
  - `/auv/sensors/depth`
  - `/auv/state/filtered`
  - `/auv/control/setpoint`
  - `/cmd_vel`

  - IMU
  - DVL
  - Depth
