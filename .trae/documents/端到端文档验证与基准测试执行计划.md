## 执行步骤

### Step 1: 编译项目

**做什么**：在 `brain_linux/` 下手动执行 colcon build，编译全部 9 个 ROS2 包。

```bash
source /opt/ros/humble/setup.bash
cd /home/auv_user/auv_ws/AUV-Master-Project/brain_linux
colcon build --cmake-clean-cache --cmake-args -DPython3_EXECUTABLE=/usr/bin/python3 -DPYTHON_EXECUTABLE=/usr/bin/python3
```

**预期**：全部包编译通过，`brain_linux/install/setup.bash` 存在。

**潜在问题**：
- conda 环境可能与 ROS2 冲突（`em` 模块缺失），需先 `conda deactivate`
- PATH 中 conda python 优先级高于系统 python

---

### Step 2: 运行 120 秒 PVS+Zenoh 实验

**做什么**：按文档执行全栈实验（rosbag 自动录制）。

```bash
cd /home/auv_user/auv_ws/AUV-Master-Project/scripts
bash start_experiment.sh --sim-backend pvs --bridge-backend zenoh_json --duration 120
```

**预期**：
- 仿真运行 120 秒后自动停止
- 产生 MCAP rosbag 于 `$AUV_DATA_ROOT/bags/YYYYMMDD_HHMMSS/rosbag/`
- 默认录制路径取决于 `AUV_DATA_ROOT` 环境变量

**潜在问题**：
- zenoh/py_trees 未安装
- `--bridge-backend zenoh_json` 是否为默认值（文档说是，需验证）
- start_experiment.sh 内部会调用 start_lin_brain.sh 触发 colcon build（可能与 Step 1 重复但无害）

---

### Step 3: 运行 ES-EKF 基准测试

**做什么**：使用 Step 2 产出的 MCAP（或已有的 `log/experiments/benchmark_120s/rosbag_mcap/rosbag_mcap_0.mcap`）运行 EKF 基准。

```bash
cd /home/auv_user/auv_ws/AUV-Master-Project
python3 tools/offline_ekf_benchmark.py \
    --input <新产生的或已有的.mcap路径> \
    --output-dir results/localization/验证运行
```

**预期**：生成 Markdown 报告 + PNG 图表于 `results/localization/验证运行/`。

**潜在问题**：
- 需要 `mcap` 和 `mcap-ros2-support` pip 包
- MCAP 中可能缺少 ground_truth 话题（PVS 后端是否发布？）
- `--dvl-frame` 默认 `world`，PVS 后端是否匹配

---

### Step 4: 运行 MPC 基准测试

**做什么**：

```bash
cd /home/auv_user/auv_ws/AUV-Master-Project
python3 tools/mpc_test.py
```

**预期**：5 张 PNG + Markdown 报告输出到 `$AUV_DATA_ROOT/results/control/mpc_test/YYYYMMDD_HHMMSS/`。

**潜在问题**：
- 依赖 `/root/PythonVehicleSimulator/src` 路径硬编码（line 24）

## 重要发现（预判风险）

1. **`get_output_dir` 路径前缀问题**：该函数产出 `{AUV_DATA_ROOT}/{sub_name}/{timestamp}/`，若 `AUV_DATA_ROOT=/tmp/auv_data`，则实际路径为 `/tmp/auv_data/results/control/mpc_test/20260601_xxx/`，而非项目内的 `results/control/`。这与 `05_benchmarks.md` 契约有出入，需在实验中验证并决定是否修正。

2. **PVS 仿真 vs ground_truth 话题**：需确认 PVS 后端是否发布 EKF 基准所需的 `/auv/sensors/ground_truth` 话题。

3. **PythonVehicleSimulator 路径硬编码**：MPC 测试依赖 `/root/PythonVehicleSimulator/src`，如果该路径不存在将失败。
