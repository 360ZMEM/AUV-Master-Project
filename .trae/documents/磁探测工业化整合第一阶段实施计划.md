# 磁探测工业化整合第一阶段实施计划

## Summary

本阶段目标是把主仓的“玩具级”电缆/磁场仿真与控制链路，收敛为主仓深度调用 `AUV-Master-Mag` 的工业化电缆探测闭环。交付边界采用分阶段主线：第一阶段实现独立 ROS2 cable tracking 节点、直接发布 `/auv/control/setpoint` 闭环、PVS/磁仓动力学约束下的 zig-zag 自动限幅、磁力计杆臂改正与标定脚本骨架、DL/T 1278 可实施核心产出物、Foxglove/GUI 自动闭环脚手架和配套文档。

已拍板决策：

- 集成方式：主仓新增 adapter 调用 `AUV-Master-Mag` 稳定 API；对子仓只做 additive API/功能补强，保持 `AUV-Master-Mag/main_demo.py` 独立运行。
- 状态机边界：主仓保留授权、仲裁、安全、急停、低层控制；`AUV-Master-Mag` 负责电缆感知、跟踪模式、zig-zag/重捕等电缆任务内部状态。
- ROS2 落点：新增独立 cable tracking 节点，不把磁探测逻辑塞进现有 `auv_decision_ros/decision_node.py`。
- 闭环方式：第一阶段直接闭环，但输出接口是 `/auv/control/setpoint`，继续走现有 controller、bridge、arbiter、安全链。
- 电缆先验输入：第一阶段支持 CSV、GeoJSON、主仓 YAML points 三种。
- 杆臂对象：第一阶段聚焦磁力计 `mag` 6D 外参；DVL/depth/IMU 继续复用现有外参体系。
- zig-zag：由 PVS/磁仓配置自动限幅，并记录限幅原因。
- DL/T 1278：先覆盖可数字孪生实施的核心项，不强行模拟港口、码头、陆上终端等不可仿真项。
- 文档：新增为主；旧 thesis/paper 先复制归档，暂不大规模改正文。

### DL/T 1278 约束

来自 `标准文档/中华人民共和国电力行业标准DLT1278-2025.md` 的本阶段相关条款：

- 9.1.3：水下运行状况检测可使用侧扫声呐、浅地层、光学、磁力仪、机器人/无人船等。
- 9.1.7：海缆路由、埋深及状态检测周期。
- 9.1.8：应检测路由变化、埋深变化、水下环境、裸露/悬跨/异物等。
- 附录 D：海缆通道检测，D.6 磁法探测要求磁法测线与目标延伸方向垂直、每个目标不少于三条测线、间距不大于 200 m、测线长度不小于 500 m、相邻测线方向相反。
- 附录 E：状态评价表包含“海缆位移、埋深不足、悬空、异物缠绕、海床运行环境恶劣、保护措施损坏”等可映射到数字孪生的核心项。

### 4. zig-zag 动力学自动限幅

文件：

- 新增 `brain_linux/src/auv_control/auv_decision_ros/cable_guidance_limits.py`
- cable tracking 节点调用该模块
- 新增测试 `brain_linux/src/auv_control/test/test_cable_guidance_limits.py`
- 可选补充 `AUV-Master-Mag/src/auv_mag_tracking/api/types.py` guidance diagnostics 字段

实现要求：

- 输入：磁仓 `CableGuidanceOutput`、当前速度、PVS/车辆约束配置。
- 输出：限幅后的 heading/speed/zigzag 字段和诊断。
- 约束：
  - `abs(delta_heading_deg) <= max_heading_delta_deg`
  - `abs(yaw_rate_deg_s) <= max_yaw_rate_deg_s`
  - 根据 `min_turn_radius_m` 和速度限制曲率：`R = v / yaw_rate_rad_s`
  - 横向速度近似限制：`v_lat = v * sin(crossing_angle)` 不超过 `max_lateral_speed_mps`
- 如果限幅发生，`/auv/cable/diagnostics` 必须写 `zigzag_limited=true` 和 `limit_reason`。
- 初始默认值采用 PVS 配置保守值：`max_yaw_rate_deg_s=12`、`min_turn_radius_m=6`、`max_lateral_speed_mps=0.45`，后续可扫参修正。

## Assumptions & Decisions

- 工业部署的现实输入以本地 NED/工程坐标为主；CSV/GeoJSON 若包含经纬度，第一阶段不在 API 内做投影，只在文档中要求预转换。
- 第一阶段直接闭环，但安全边界不下沉到磁仓；所有实物安全仍由主仓 `auv_bridge`、`AutonomyGuard`、`CommandArbiter`、控制器限幅和现有协议链负责。
- `AUV-Master-Mag` 的 API 是算法权威源；主仓 adapter 不复制核心磁探测算法。
- 主仓仿真侧继续生成基础磁力计/声呐原始观测，但在线电缆位置、埋深、进度、状态由 `AUV-Master-Mag` 输出。
- Foxglove 公网登录需要用户介入，脚手架只负责登录后的浏览器/截图/检查闭环。
- GUI 自动闭环第一阶段以截图和非危险交互为主，不自动执行高风险实物控制动作。
- DL/T 1278 的评分第一阶段是“标准风格数字孪生评分”，不是完整法定状态评价替代品。
