# 工业验收结论补强计划

## Summary

本计划面向当前声磁电缆探测全流程运行后的 `industrial_conclusion_readiness=limited` 结论，目标是把系统从“能生成 DL/T 1278 风格产物的全流程样张”推进到“可支撑初步工业验收判断的证据链”。

当前全流程已经证明：

- PVS/protocol_udp 可以稳定输出 `/auv/sensors/magnetic`。
- `auv_cable_tracking_node` 可以调用 `AUV-Master-Mag`，发布 `/auv/cable/tracking` 和 `/auv/control/setpoint`。
- rosbag 可以记录 magnetic、tracking、setpoint、mission 等关键 topic。
- 离线工具可以生成 DL/T 1278 风格 CSV、Markdown 报告和图件。

但当前不能给出工业级“正常/合格”结论，直接原因是：

- `AUV-Master-Mag/src/auv_mag_tracking/api/pipeline.py` 仍是 route projection facade，公开 API 未真正消费磁感知结果。
- `/auv/cable/tracking` 中 `confidence` 固定为 `0.5`，没有动态可信度。
- `burial_sigma_m` 为 `None`，无法判定 DL/T 1278 中埋深 0.15 m 精度目标。
- route offset 偏大，上一轮最大值 `14.717 m`、平均值 `3.876 m`。
- mission 仍需手动 `ros2 topic pub` 注入，复现实验自动化不足。
- 还没有 ≥3 次重复运行统计，不能形成稳定工业指标。

计划分为两条主线：

1. **AUV-Master-Mag 子仓补强**：让公开 API 接入已有的磁感知置信度、埋深不确定度、先验配准残差和诊断字段，保持 `main_viz.py` 独立运行能力。
2. **主仓补强**：让 ROS adapter、实验 runner、DL/T 报告、可视化和文档消费这些真实指标，并形成多次运行统计和工业验收门槛。

## Proposed Changes

### Phase 1：AUV-Master-Mag 公开 API 接入真实质量指标

目标：先不大改子仓内部仿真主流程，不破坏 `main_viz.py`；只增强部署公开 API，让主仓可以拿到动态 confidence、burial sigma 和 residual 诊断。

#### 1.1 扩展 API 配置入口

文件：

- `AUV-Master-Mag/src/auv_mag_tracking/api/types.py`
- `AUV-Master-Mag/src/auv_mag_tracking/api/pipeline.py`

改动：

- 新增部署 API 配置数据类，例如 `DeploymentPerceptionConfig`，字段包括：
  - `enable_magnetic_quality: bool = True`
  - `enable_burial_inversion: bool = True`
  - `magnetic_noise_floor_nt: float`
  - `burial_coupling_constant_nt_m_per_a_rms: float`
  - `burial_current_rms_a: float`
  - `burial_altitude_m: float`
  - `burial_snr_gate_db: float`
  - `burial_min_strength_nt: float`
  - `burial_min_samples: int`
  - `burial_max_lateral_offset_m: float`
  - `confidence_min_ready: float`
  - `route_offset_ready_m: float`
- `AuvMagTrackingPipeline.__init__()` 增加可选参数：
  - `deployment_config: DeploymentPerceptionConfig | None = None`
- 默认保持当前行为兼容：如果未传 `deployment_config`，仍可 route projection fallback。

验收：

- 旧的 API 调用不需要改动即可通过。
- 新配置开启后，输出诊断中必须出现 `full_perception_stack_connected=True` 或更准确的 `deployment_quality_connected=True`。

#### 1.2 新增轻量部署质量估计器

文件：

- 新增 `AUV-Master-Mag/src/auv_mag_tracking/api/deployment_quality.py`
- 修改 `AUV-Master-Mag/src/auv_mag_tracking/api/pipeline.py`

改动：

- 实现纯函数/轻量类 `DeploymentQualityEstimator`，输入：
  - `NavigationInput`
  - `MagneticInput`
  - route projection 结果
  - 可选 `SonarInput`
- 输出结构建议命名为 `DeploymentQualityOutput`，包含：
  - `magnetic_strength_nt`
  - `magnetic_std_nt`
  - `snr_db`
  - `magnetic_confidence`
  - `fit_residual_m`
  - `prior_alignment_residual_m`
  - `confidence`
  - `quality_flags`
- 初版不强行接入完整 `orchestrator.py`，先复用已有思想：
  - 用 `sample_block_nt` 的 norm/方差估计信号强度与稳定性。
  - 用 route projection distance 作为 `fit_residual_m` 或 `prior_alignment_residual_m` 的保守代理。
  - 复用 `perception/confidence.py::ConfidenceEstimator` 的评分函数。
- `CableTrackingOutput.confidence` 不再固定 `0.5`，而由 `DeploymentQualityEstimator` 生成。
- `diagnostics` 增加：
  - `magnetic_used`
  - `magnetic_strength_nt`
  - `magnetic_snr_db`
  - `magnetic_confidence`
  - `fit_residual_m`
  - `quality_flags`

验收：

- 在无磁输入或磁输入无效时，输出明确 fallback：
  - `magnetic_used=False`
  - `mode="map_fallback"` 或 `mode="quality_limited"`
  - `confidence < confidence_min_ready`
- 在有效磁输入时，`confidence` 随信号质量变化，不能全程常数。

#### 1.3 将磁法埋深反演接入 API

文件：

- `AUV-Master-Mag/src/auv_mag_tracking/api/deployment_quality.py`
- `AUV-Master-Mag/src/auv_mag_tracking/api/pipeline.py`
- 复用 `AUV-Master-Mag/src/auv_mag_tracking/perception/burial_inversion.py`

改动：

- 在 `AuvMagTrackingPipeline` 内部持有 `MagneticBurialInverter` 实例。
- 每次 `step()` 时，用以下数据更新 inverter：
  - `strength_nt`：来自 `MagneticInput.sample_block_nt` 的处理强度。
  - `lateral_offset_m`：route projection 的 signed/absolute cross-track。
  - `snr_db`：来自轻量质量估计。
- 若 inverter 输出成熟：
  - `CableTrackingOutput.burial_depth_m = estimate.depth_m`
  - `CableTrackingOutput.burial_sigma_m = estimate.sigma_m`
  - `diagnostics["burial_fit_quality"] = estimate.fit_quality`
  - `diagnostics["burial_sample_count"] = ...`
- 若 inverter 未成熟：
  - `burial_depth_m` 可继续使用 cable map 先验。
  - `burial_sigma_m = None`
  - `diagnostics["burial_status"] = "warming_up"`。

验收：

- 当 `burial_min_samples` 达到后，`burial_sigma_m` 不再长期为 `None`。
- 报告工具可以判断 `burial_accuracy_pass` 为 true/false，而不是 null。

## Assumptions & Decisions

1. 不在本阶段删除旧的 route projection fallback。它仍是无磁/弱磁/调试场景下的保守后备。
2. `AUV-Master-Mag` 的改动优先落在 `api/` 和轻量 deployment quality 层，不直接大改 `main_viz.py` 和离线仿真主流程。
3. 子仓内部已有的 `ConfidenceEstimator`、`MagneticBurialInverter`、`PerceptionState` 是首选复用对象，不重新发明一套主仓私有算法。
4. 主仓只消费公开 API 输出，不直接 import 子仓 `perception/orchestrator.py` 的内部复杂对象，避免耦合过深。
5. DL/T 1278 风格评分和工业验收建议必须分开显示。评分为“正常状态”时，如果证据质量不足，仍应输出 `industrial_conclusion_readiness=limited`。
6. `--arbiter-profile` 是 protocol_udp fullflow 的必要参数，后续 fullflow preset 必须显式包含。
7. 多次运行统计的最低门槛为 3 次 fullflow run；论文或验收材料中不能用单次 run 声称稳定工业性能。
