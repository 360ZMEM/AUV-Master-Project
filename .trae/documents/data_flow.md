
## 详细数据流

### 1. 传感器数据流向

```
传感器采集 → enrich_meta() 添加时间戳 → validate_sensor_payload() → Zenoh 发布
                                                               │
                                                               ▼

                                                               │
                                                               ▼
                                                    ROS2 消息转换
                                                               │
                               ┌───────────────────────────────┼───────────────────────────────┐
                               ▼                               ▼                               ▼
                        Localization                      Controller                       Decision
                           Node                             Node                             Node
                    (状态估计)                          (控制计算)                        (行为决策)
```

## 数据格式转换

### Zenoh → ROS2 转换

| Zenoh 键 | ROS2 消息字段 | 转换规则 |
|----------|---------------|----------|
| `position_ned` | `pose.pose.position` | 直接映射，z 取反 |
| `rpy_ned` | `pose.pose.orientation` | RPY → 四元数 |
| `vel_ned` | `twist.twist.linear` | 直接映射 |
| `accel_ned` | `linear_acceleration` | 直接映射 |
| `gyro_ned` | `angular_velocity` | 直接映射 |
| `depth_m` | `pose.pose.position.z` | 取负值 |

### ROS2 → Zenoh 转换

| ROS2 消息 | Zenoh 键 | 转换规则 |
|-----------|----------|----------|
| `Twist.linear.x` | `thrust` | 直接映射 |
| `Twist.angular.x` | `right` | 直接映射 |
| `Twist.angular.y` | `top` | 直接映射 |
| `Twist.angular.z` | `left` | 直接映射 |
| `Twist.linear.z` | `bottom` | 直接映射 |

## 时间同步

### 时间戳字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `step` | int | 仿真步数 |
| `sim_time` | float | 仿真时间（秒） |
| `ts` | float | 系统时间戳（Unix 秒） |
| `mock_amd_timestamp_us` | int | Mock AMD 时间戳（微秒） |

### 延迟计算

```python
# 从传感器到控制输出的延迟
sensor_to_cmd = now - max(latest_setpoint_ts, state_ts)
```

### 超时阈值

| 组件 | 超时时间 | 说明 |
|------|----------|------|
| MPC 命令 | 0.5s | `mpc_timeout_s` |
| IMU 数据 | 0.5s | IMU 回退阈值 |
| 遥测数据 | 可配置 | 新鲜度检查 |

## 数据验证

### 传感器数据验证

```python
ok, errors = validate_sensor_payload(topic, payload)
# 验证内容：
# 1. payload 必须是 dict
# 2. 必需字段检查
# 3. 数据类型检查（数字、列表长度等）
# 4. 元数据字段类型检查
```

### 控制命令验证

```python
ok, errors = validate_control_payload(payload)
# 验证内容：
# 1. 格式识别（dict/list/tuple）
# 2. 控制向量长度（必须为 5）
# 3. 值必须为数字
# 4. 边界检查（舵角 ±30°，推力 -100~100%）
```

## 关键主题映射

### Zenoh 主题

| 主题 | 方向 | 频率 | 数据量 |
|------|------|------|--------|
| `rt/auv/sensors/imu` | 发布 | 100Hz | ~100B |
| `rt/auv/sensors/dvl` | 发布 | 10Hz | ~50B |

| `rt/auv/sensors/ground_truth` | 发布 | 30Hz | ~150B |
